# Notes partie 2 : Livre I, leçons 41 à 81

## 0. Attention : la numérotation des classes du livre n'est PAS la nôtre
Le livre compte les classes par paires singulier/pluriel. Correspondance :

| Livre | préfixes | Nos classes |
|---|---|---|
| 1 | umu-/aba- (personnes) | 1/2 |
| 2 | umu-/imi- | 3/4 |
| 3 | in-/in- | 9/10 |
| 4 | iki-/ibi- | 7/8 |
| 5 | i(ri)-/ama- | 5/6 |
| 6 | uru-/in- | 11/10 |
| 7 | aka-/utu- | 12/13 |
| 8 | ubu-/ama- | 14/6 |
| 9 | uku-/ama- | 15/6 |
| 10 | aha- | 16 |

Dans ces notes, j'utilise NOS numéros, sauf quand je cite le livre.
Imana (Dieu) est "3e classe" dans le livre = notre classe 9.

## a) Règles de grammaire

### R1. -ose (tout, chaque) (L41, par. 84-87)
Préfixe = lettre de la classe + -ose. Cl.1 : **wese** (pas wose !), cl.2 bose, cl.3 wose, cl.4 yose,
cl.5 ryose, cl.6 yose, cl.7 cose, cl.8 vyose, cl.9 yose, cl.10 zose, cl.11 rwose, cl.12 kose,
cl.13 twose, cl.14 bwose, cl.15 kwose, cl.16 hose. Singulier = "tout entier" ou "chaque", pluriel = "tous".
Se place APRÈS le nom et après tous les autres adjectifs. twese = nous tous, mwese = vous tous, bose = eux tous.
- inzu yose = toute la maison ; umuntu wese = chaque personne ; imisi yose = tous les jours.

### R2. ryari (quand ?) (L41, par. 88)
Seulement en question, en fin de phrase. Uzogenda i Gitega ryari ? = Quand iras-tu à Gitega ?

### R3. Impératif des verbes à voyelle (L42, par. 91)
Radical seul : Oza amasahane = Lave la vaisselle ; Andika izina ryawe = Écris ton nom.

### R4. -ndi (autre) (L43, par. 92-93)
Forme : voyelle initiale + consonne de classe + -ndi : uwundi (1, 3), abandi (2), iyindi (4, 9), irindi (5),
ayandi (6), ikindi (7), ibindi (8), izindi (10), urundi (11), akandi (12), utundi (13), ubundi (14), ukundi (15), ahandi (16).
Se place AVANT le nom, et le nom perd sa voyelle initiale. Peut vouloir dire "de plus".
- abandi bantu = d'autres gens (pas "abandi abantu") ; ikindi gitabo = un autre livre ;
- Mfise ibiti bitatu yamara ngomba ibindi bibiri = J'ai trois arbres mais j'en veux deux de plus.

### R5. gusubira + infinitif = refaire (L44, par. 94)
Subira kwandika = Écris encore. Seul, avec i long : Sinzosubīra = Je ne le referai plus.

### R6. gusaba / kubaza / gusenga (L44, par. 95)
kubaza = poser une question ; gusaba = demander quelque chose, prier Dieu pour obtenir ; gusenga = prier (adorer).

### R7. Verbe défectif -zi (savoir) (L45, par. 96-98)
Présent -ra- : ndazi, urazi, arazi, turazi, murazi, barazi. Négatif : sinzi, ntuzi, ntazi, ntituzi, ntimuzi, ntibazi.
Présent sans -ra- : nzi, uzi, azi. PAS de futur, PAS de passé, PAS d'infinitif : on prend kumenya.
Même chose pour -ri (être) -> kuba et -fise (avoir) -> kugira.
"Ndabizi ?" = Est-ce que je sais, moi ? (réponse évasive).

### R8. Tableau des adjectifs (L46, par. 99)
Adjectif simple -bi : mubi/babi (1/2), mubi/mibi (3/4), mbi/mbi (9/10), kibi/bibi, ribi/mabi, rubi, kabi/tubi, bubi, kubi, habi.
Nombre "un/deux" : umwe/babiri, umwe/ibiri, imwe/zibiri, kimwe/bibiri, rimwe/abiri, rumwe, kamwe/tubiri, bumwe, kumwe, hamwe.
-ngahe (combien) : bangahe, ingahe (cl.4), zingahe, bingahe, angahe, tungahe, hangahe.

### R9. Ordre des mots (L47, par. 100-102)
Possessif juste après le nom ; -ndi avant le nom ; -ngahe tout à la fin ; -ose après les autres adjectifs ;
les nombres après les adjectifs ; -inshi et -ke souvent en dernier.
-inshi / -ke au singulier = choses qu'on ne compte pas : ifu nyinshi = beaucoup de farine ; umunyu muke = un peu de sel ;
umuyaga mwinshi = vent fort (jamais munini).
Adverbe après le mot qu'il modifie : Umugabo mwiza arakora cane (travaille beaucoup) / Umugabo mwiza cane arakora (très bon).

### R10. Pronoms personnels forts (L48, par. 103)
jewe (je), wewe (we), we, twebwe (twe), mwebwe (mwe), bo. Seulement pour insister, JAMAIS comme objet
du verbe ("Ndabona wewe" est faux). Jewe nzoguma hano ariko wewe uzogenda.

### R11. mu/ku -> muri/kuri (L48, par. 104)
Devant un nom propre, un mot sans voyelle initiale, un pronom fort, un démonstratif :
muri Yesu, kuri twebwe, muri mwebwe (parmi vous). Exception : ku Muyebe.

### R12. Passé ordinaire (L51, L54, par. 105-106, 110-111)
SUJET + a + PERFECTIF : nakoze, wakoze, yakoze, twakoze, mwakoze, bakoze.
Sert surtout pour ce qui s'est passé AUJOURD'HUI (ton bas). Avec les autres classes : cl.3 wagiye, cl.4 yagiye,
cl.9 yagiye, cl.10 zagiye, cl.7 cagiye, cl.8 vyagiye, cl.5 ryagiye, cl.6 yagiye, cl.11 rwagiye, cl.12 kagiye, cl.13 twagiye, cl.14 bwagiye, cl.15 kwagiye.
Verbes à voyelle : le a tombe : nibagiye (j'ai oublié), yubatse, bemeye, twogeje, mwanditse.

### R13. Règles du perfectif (L52-53, par. 107-109)
-ba -> -vye (gomvye) ; -da/-ga -> -ze (henze, vuze) ; -ha -> -she (ubashe) ; -ka -> -tse (tetse) ; -ma -> -mye (somye) ;
-na -> -nye/-nnye (bonye, kennye) ; -nya -> -nije/-nye (gabanije, menye) ; -nka -> -nse (ronse) ; -sa -> -she (meshe) ;
-ta -> -se/-she (kubise, fashe) ; -sha -> -shije/-sheje (igishije, nesheje) ; -za -> -je/-jije/-jeje (je, kijije, ejeje).
-ra : 2 syllabes, 1re longue -> -ye (tēye) ; 2 syllabes, 1re courte -> -ze (guze, rize, shize) ;
plus de 2 syllabes -> -ye (injiye, hariye) ; -īra/-ēra long -> -iriye/-ereye (sinziriye, subiriye).
Verbes d'une syllabe : à apprendre un par un (riye, nyoye, haye, pfuye, guye, je, ishe).
Liste complète des perfectifs : voir vocab (L53).

### R14. Négatif du passé ordinaire (L55, par. 112)
nti + sujet + a + perfectif : sinagiye, ntiwagiye, ntiyagiye, ntitwagiye, ntimwagiye, ntibagiye ;
voyelle : sinogeje, ntibubatse ; classe 10 : ntizagiye.

### R15. Passé de -ri (L56, par. 114-115)
nari, wari, yari, twari, mwari, bari (seule forme pour tout passé de "être"). Négatif sinari, ntiwari...
Passé continu : twariko turaheza ibikorwa = nous étions en train de finir (2e verbe au présent -ra-).

### R16. Pronoms objets dans le verbe (L57-59, par. 116-121)
Place : après le marqueur de temps, juste avant le radical.
Personnes : -n-/-m- (me), -ku-/-gu- (te), -mu- (le/la, personne), -tu-/-du- (nous), -ba- (vous), -ba- (les, personnes).
Classes : 3 -wu-, 4 -yi-, 5 -ri-, 6 -ya-, 7 -ki-, 8 -bi-, 9 -yi-, 10 -zi-, 11 -ru-, 12 -ka-, 13 -tu-, 14 -bu-, 15 -ku-, 16 -ha-.
Même pronom pour objet direct ou indirect : Ndaguha igitabo = Je te donne le livre.
Loi de Dahl sur le pronom (ku->gu, tu->du devant p t k c f s h), mais le pronom ne change pas la syllabe d'avant : ndagusaba, kukubona.
n + h -> mp : mpa (donne-moi), yampariye (il m'a pardonné).
Devant voyelle : mu->mw (bamwanka), tu->tw (batwigisha), ku->kw (ndakwizera), ru->rw (yarwivye), ba->b (ndabereka),
yi/zi perdent le i (arazica, yayibagiye), ki->c (ndacibuka), bi->vy (navyibagiye), ri->ry (yaryivye), n (me)->ny (anyereka).
Futur + objet : kw disparaît : nzocibuka, nzobereka (nzokwereka = je te montrerai OU je montrerai).
Deux pronoms : direct avant indirect : Nakimuhaye = Je le lui ai donné.
Exemples : Ndagifise (je l'ai, le livre) ; Nahabonye (je l'ai vu, l'endroit) ; Ararufise (il l'a, la clé).

### R17. Nombres ordinaux et adverbes de fois (L61, par. 122-125)
Particule "de" + ka-forme (2 à 6), forme simple (7 à 10), mbere pour "premier" :
umuntu wa mbere, inzu ya gatatu, akayabo k'indwi, igiti c'icumi, inanasi y'icumi na rimwe (11e : rimwe, pas mbere).
Dernier : w'impera. Une/deux fois : rimwe, kabiri, gatatu ; kenshi = souvent ; kangahe ? = combien de fois ?
-ompi = les deux (quand il n'y en a que deux) : bompi, twempi, mwempi.

### R18. Mois, jours, heures (L62, par. 126-128)
Ukwezi kwa mbere = janvier ; Umusi wa mbere = lundi ; Umusi w'Imana = dimanche ; ku wa gatanu = vendredi.
Itariki ya 23 y'ukwezi kwa kane = le 23 avril. Heure : la journée commence à 6 h. isaha imwe = 7 h,
isaha zitatu = 9 h, isaha sita = midi. isaha zitatu n'igice = 9 h 30 ; isaha zine zibuzemw' amadakika cumi = 9 h 50.
Durée : amasaha atatu = trois heures.

### R19. Statif (L64, par. 130 ; L72 par. 146)
Verbes d'état : -ra- + PERFECTIF au présent : Ndarwaye (je suis malade), Ndanezerewe (je suis heureux),
Ndicaye (je suis assis), Ndizeye (j'ai confiance), Biragoye (c'est difficile), Turashonje (nous avons faim).
Négatif et propositions dépendantes : sans -ra-. Habituel : présent normal.
Arahwereye = il est très malade (yarahwereye = il est mort).

### R20. Particule -o + infinitif (L65 par. 131 ; L69 par. 139-141)
Nom + particule "de" avec a -> o + infinitif = "pour (faire)" : umusumeno wo gusatura ibiti, inkomezi zo kunesha Satani.
na -> no devant infinitif et devant mu/ku : kurya no kunywa ; ku meza no ku ntebe.
wa -> wo devant mu/ku pour un lieu : ibiti vyo mw ishamba ; Igitabo co ku meza ni ciza (le livre sur la table est bon).
Une partie ne "possède" pas : amababi yo ku mashami, mais amababi y'igiti.

### R21. Impératif pluriel, subjonctif (L66-67, par. 132-135)
Pluriel : mu + radical + e : mugende, mukore ; poli : Ni mugende.
Avec un pronom objet (sauf "me"), le a final devient e : muhe, duhe, mais mpa.
Subjonctif = sujet + radical + e : ukore, wandike, uzane, tugende (allons), akore (qu'il travaille), batangure.
Sert pour le 2e de deux ordres : Zana ibijumbu ubiteke. kugira ngo / ngo "pour que" + subjonctif : Araza kugira ngo yigishwe.

### R22. Négatif impératif / subjonctif (L68, par. 137)
ntugende, ntimugende, ntagende (le tableau écrit "ntagenda"), ntibagende.

### R23. Suffixe -ho (là, ici) (L68, par. 138)
Wariho ejo ? Ego, nariho. Ndiho = je suis là (ou je suis vivant). Nawushizeho = je l'y ai posée.

### R24. Passé lointain -ara- (L71-72, par. 142-143)
Pour hier ou avant : sujet + ara + perfectif : narakoze, warakoze, yarakoze, twārakoze, mwārakoze, bārakoze ;
voyelle : naribagiye. Seulement quand RIEN ne suit le verbe (sauf cane ou ati).
Si un complément suit : -ra- tombe : nakoze ibikorwa (même écrit que le passé du jour, ton haut).
Négatif et propositions dépendantes : sans -ra- (sinagiye...).

### R25. Ordre des objets nominaux (L72, par. 144)
Objet indirect d'abord : Nahaye Petero igitabo ; sauf s'il est long : Nahaye igitabo umwana wa Petero.
hirya y'ejo = avant-hier ou après-demain (selon le temps).

### R26. Père, mère, frères, soeurs (L73-74, par. 147-149)
data/dawe (mon père), so (ton père), se (son père) ; mama/mawe, nyoko (ou mama wawe, plus poli), nyina.
Pas de possessif. data wacu = oncle paternel ; "Notre Père" = Data wa twese. Pluriel : ba so, ba nyina.
mushiki (soeur d'un garçon), musaza (frère d'une fille), mukuru (aîné même sexe), murumuna (cadet même sexe) :
mushikanje, mushikawe, mushiki we ; mukurwanje ; murumunanje. Muravukana ? = êtes-vous frère et soeur ?

### R27. Passé immédiat -ra- (L75, par. 150-152)
sujet + ra + perfectif : ndagiye (je viens de partir), aragiye, baragiye. Ndaje = j'arrive.
Négatif et propositions dépendantes : sans -ra-.

### R28. Possessifs avec un possesseur non humain (L76-77, par. 153-155)
1re partie = particule de la chose possédée ; 2e partie = particule du possesseur avec a -> o :
umurizo wayo (sa queue, la vache cl.9), ijambo ryayo (Sa parole, Dieu), umuzi waco / imizi yavyo (arbre cl.7/8),
amenyo yayo, imitwe yavyo. Possesseur humain : -iwe (lui) / -abo (eux) : umwana wiwe, abana babo.

### R29. Causatif -isha/-esha (L78-80, par. 156-162)
Règle A I U : avant-dernière syllabe en a, i, u -> -isha ; en e, o -> -esha : gukora -> gukoresha, kuririmba -> kuririmbisha.
Sens : faire faire, ou utiliser (gukoresha isuka = se servir d'une houe). Perfectif : -sheje/-shije (yakoresheje).
Irréguliers : -za -> -risha (gukirisha) ; -ra -> -za (kubabaza) ; monosyllabes : kugwisha, kunywesha, gusyesha, kuvisha, guhesha, kurisha, gutesha ;
gukura -> gukuza, kubora -> kuboza.
Deux objets : celui qui "fait" ou l'instrument d'abord, le vrai objet ensuite (gukebesha imbugita urutoke), mais l'ordre peut varier.

## b) Comparaison avec nos générateurs

**Attention générale** : les numéros de classe du livre ne sont pas les nôtres (voir section 0). Nos tableaux utilisent la bonne
numérotation standard, pas de problème tant qu'on ne copie pas les numéros du livre.

| Règle chez nous | Verdict | Preuve |
|---|---|---|
| Passé -a- + perfectif (nakoze ... bakoze) | CONFIRMÉE | L51 : "nakoze, wakoze, yakoze, twakoze, mwakoze, bakoze" |
| Passé, verbes à voyelle (a tombe : nize, mwize) | CONFIRMÉE | L54 : "nibagiye, yubatse, bemeye, twogeje, mwanditse" |
| Négatif passé (sinakoze, ntiwakoze...) | CONFIRMÉE | L55 : "sinagiye, ntiwagiye, ntiyagiye, ntitwagiye, ntimwagiye, ntibagiye", "sinogeje, ntibubatse" |
| Passé avec -ra- (narakoze) | INCOMPLÈTE / risque d'ERREUR | L71 : c'est le passé LOINTAIN (hier ou avant), et "If something follows the verb, the ra is dropped". Donc "narakoze ibikorwa" est faux ; il faut "nakoze ibikorwa". Aussi, jamais de -ra- au négatif ni en proposition dépendante. |
| "narize" (kwiga, passé -ra-) ? | Probablement JUSTE | Par analogie avec L71 "naribagiye, waribagiye, yaribagiye" (na-ra-ibagiye -> naribagiye). Donc narize, warize, yarize (sans complément). |

### Ce que nos générateurs ne savent PAS faire et que cette partie enseigne
1. Passé lointain -ara- avec la règle "pas de complément" (R24).
2. Passé immédiat -ra- + perfectif (ndagiye) (R27).
3. Statif -ra- + perfectif = état présent (ndarwaye, ndanezerewe, biragoye) (R19).
4. Passé de -ri : nari ... bari ; passé continu "twariko turaheza" (R15).
5. Pronoms objets avec toutes les règles de son (R16), deux pronoms (direct puis indirect).
6. Impératif pluriel, subjonctif, négatif impératif (R21-R22).
7. Causatif -isha/-esha avec la règle A I U et le perfectif -sheje/-shije (R29).
8. -ose, -ndi (avant le nom, nom sans voyelle initiale), -ngahe, -ompi, ordinaux (R1, R4, R8, R17).
9. Accords du passé avec toutes les classes : cl.7 cagiye, cl.8 vyagiye, cl.5 ryagiye, cl.11 rwagiye... (R12).
10. Particule wo/yo/co + infinitif ou + mu/ku ; na -> no (R20).
11. -zi : pas de futur ni de passé (ne pas générer "nzozi" ou "nazi").

## c) Pièges de traduction français <-> kirundi

- **Pronom objet qui reprend un nom** : "Ufise igitabo ? Ndagifise" = "As-tu un livre ? Je l'ai". En français, "le/la/les" ne dit pas la classe ;
  en kirundi il faut choisir -ki-, -ri-, -bi-, -zi-, etc. selon le nom repris. Dans l'autre sens, traduire "Ndagifise" par "je l'ai", pas "j'ai".
- **Pronom fort comme objet = faute** : "Je te vois" = Ndakubona, jamais "Ndabona wewe".
- **"de" possessif ou de lieu** : "les arbres de la forêt" = ibiti vyo mw ishamba (pas vya ishamba) ; "le livre sur la table" = igitabo co ku meza.
- **Le passé** : le français "j'ai travaillé" correspond à 3 formes : nakoze (aujourd'hui), narakoze (hier ou avant, sans complément),
  ndakoze (à l'instant). "Ndaje" = "J'arrive", pas "je suis venu". Le passé du jour et le passé lointain avec complément s'écrivent pareil (seul le ton change) :
  sans contexte, "Nakoze ibikorwa" est ambigu.
- **Statif** : "Ndarwaye" = "je suis malade" (présent !), pas "j'ai été malade". "Arahwereye" = "il est très malade", "yarahwereye" = "il est mort".
- **"Tous les jours"** : imisi yose (pluriel), même si le français dit "chaque jour".
- **-ndi = "de plus"** : ngomba ibindi bibiri = "j'en veux deux de plus".
- **hirya y'ejo** = avant-hier OU après-demain ; c'est le temps du verbe qui décide. De même "ejo" = hier ou demain.
- **"Laver"** : 6 verbes selon l'objet : kumesa/kumesura (linge), kwoza (vaisselle, sol), gukaraba (mains, sans dire "mains"), kwoga/kwiyoga (pieds, corps), kwiyuhagira (bain), kuronga (légumes).
- **"Demander"** : kubaza (question) / gusaba (obtenir). **"Arrêter"** : guhagarara (s'arrêter, attendre), kureka (cesser), kubuza (empêcher).
- **"Attendre"** : kurorera (Undorere = attends-moi), guhagarara. **"Se lever"** : kuva hasi ; "être debout" : guhagarara.
- **Famille** : "mon père" = data (sans possessif) ; "data wacu" = mon oncle ! "Notre Père" = Data wa twese. Frère/soeur dépend du sexe des deux personnes.
  nyoko peut être vexant : préférer mama wawe.
- **Dieu** : possessif -ayo (ijambo ryayo, ubwami bwayo), pas -iwe.
- **Causatif = "avec"** : "couper avec un couteau" = gukebesha imbugita ; pas de mot pour "avec". Le causatif peut être ambigu (kumugukundisha).
- **gupfa** pour un objet : umupira wapfuye = le pneu est crevé.
- **"Et" entre deux ordres** : pas de "na" : Genda urondere isuka = Va chercher une houe.
- **mu -> muri** devant un nom propre ou un pronom (muri Yesu, muri bo = parmi eux).
- **Heures** : isaha imwe = 7 h (décalage de 6 h) !
- **Erreurs du livre à ne pas apprendre** : "kubwira – to sell" (L66) : kubwira veut dire "dire à" (voir "Mubwire umugabo kuza") ;
  "Ndakubone" (L57) pour Ndakubona ; "unkundi kuboko" (L43) pour ukundi ; "kureke" et "guhagaraza (hagaze)" (L67) pour kureka et guhagarara ;
  "ntagenda" (L68) pour ntagende ; "amaso yaje yompi" (L61) sans doute pour yanje ; "Ndawara" (L64) pour ndarwara (?).
- Les phrases des exercices "Translate into English" n'ont PAS de traduction : je ne les ai pas mises dans les paires.
  Le texte de lecture de la leçon 50 (Joseph et ses frères) non plus.
