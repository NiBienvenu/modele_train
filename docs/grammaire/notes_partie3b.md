## a) Règles de grammaire et d'orthographe

### R1. Les temps du verbe (tableau de l'annexe, verbe gukora "travailler")

| Temps (nom du livre) | Forme | Exemple (je / nous) | Sens français |
|---|---|---|---|
| Présent simple | sujet + ra + racine | ndakora / turakora | je travaille |
| Présent continu | sujet + ri + ko, puis sujet + ra + racine | ndiko ndakora, urik' urakora, arikw' arakora, turiko turakora | je suis en train de travailler |
| Présent habituel | sujet + racine | nkora / dukora | je travaille (d'habitude, avec complément) |
| Présent "encore" | sujet + raca + racine | ndacakora / turacakora | je travaille encore |
| Passé ordinaire (aujourd'hui) | sujet + a + perfectif | nakoze / twakoze | j'ai travaillé (aujourd'hui) |
| Passé lointain 1 (hier et avant) | sujet + a + perfectif (même écriture, ton différent) | nakoze / twakoze | j'ai travaillé (hier) |
| Passé immédiat | sujet + ra + perfectif | ndakoze / turakoze | je viens de travailler |
| Passé lointain 2 (hier et avant) | sujet + ara + perfectif | narakoze / twarakoze | j'ai travaillé (hier ou avant) |
| Futur simple (demain et après) | sujet + zo + racine | nzokora / tuzokora | je travaillerai |
| Futur immédiat (bientôt, aujourd'hui) | sujet + ribu + racine + e | ndibukore / turibukore | je vais bientôt travailler |
| Négatif présent | si/nti + sujet + racine | sinkora / ntidukora | je ne travaille pas |
| "Pas encore" | si/nti + sujet + ra + racine | sindakora / ntiturakora | je ne travaille pas encore |
| Impératif | sg : racine ; pl : mu + racine + e | kora ; mukore ; ni mukore (poli) | travaille ! travaillez ! |
| Impératif négatif | nti + sujet + racine + e | ntukore, ntimukore, ntibakore | ne travaille pas ! |

Notes du livre (p. 158-159) :
- Passé lointain 1 : "distinguished from the Ordinary Near Past only by the intonation and emphasis of the first vowel of the stem (long and high tone). It is used if nothing follows the verb, in dependent clauses and in the negative."
- Passé lointain 2 (-ara-) : "-ara- est court au singulier, long au pluriel ; tons hauts."
- Impératif négatif 3e sg écrit "ntakora" (sans -e). Les autres formes ont -e. Sans doute une coquille (ntakore attendu). À vérifier.
- Le présent continu fait l'élision normale : uriko + urakora -> urik' urakora ; ariko + arakora -> arikw' arakora (o -> w devant a).

### R2. Les apostrophes (élision) : règles officielles, en français

Règle 1a. On met une apostrophe à ces mots quand ils sont suivis d'une voyelle :
na, ni, si, -ri, -ti, yamara, ingene, ariko, kubwa, maze, mbega, nka, canke, none, kandi, rero, mbere, erega, ehe, buno, asangwa, namba, naho, iyo (conjonction), muri, kuri, hako.
Exemples : N'abandi. N'umwigisha. S'umuhungu. Ar' i muhira. At' Uzoza ryari? Yamar' abana. Ingen' abikoze. Arik' umuntu wese. Kubw' ivyo. Maz' aragenda. Mbeg' uzoza? Nk'abana. Cank' ibiti. Non' ubu. Kand' abantu. Rer' umuntu wese. Mber' aragiye. Ereg' ivyiwe vyaheze. Eh' ari hano. Bun' aragenda. Mur' iyo nzu. Kur' uyo. Namb' abikora. Hak' ubiheba.
- Espace : après na, ni, si, nka il n'y a PAS d'espace (n'abandi, nk'abana). Après les autres mots, on laisse un espace (Arik' umuntu, Maz' aragenda).

Règle 1b. kuko, ko, yuko, nuko, ngo, uko : le o devient w devant a, e, i ; il devient apostrophe devant u.
Exemples : Kukw afise. Yukw iri hano. Kuk' uzogenda. Ng' ubibone. Uk' ugomba.

Règle 1c. On écrit n'ingoga (vite), pas ningoga : Bikore n'ingoga.
Règle 1d. N'iki prend l'apostrophe : N'iki gituma.
Règle 1e. ahi, iyo : le dernier son devient apostrophe devant toutes les voyelles : Ah' uzozira. Ah' ashaka. Iy' ataje.
Règle 1f. Avec -za auxiliaire (futur impératif ou subjonctif) : Uz' ugende. Az' abimenye.
Règle 1g. La particule possessive (wa, ya, ca...) s'élide : w'umusore, c'Imana.

Règle 2a. PAS d'apostrophe aux pronoms personnels, démonstratifs, numéraux, de quantité, interrogatifs :
Ni we azogenda (pas Ni w'azogenda). Uyo arakora (pas Uy' arakora). Nta co ukoze. Iyi irarwaye. Har' ico ubona? N'ico uyu akoze kizovuga. Batangazwa n'ivyo abishura. Ni nde azogenda?
Règle 2b. Peuvent prendre l'apostrophe : le pronom possessif (ivy' abantu pour ivya abantu, iz' abakuru, ab' iki gihe) et le démonstratif dans : ic' ari co, uw' ari we, ivy' ari vyo.

Règle 3. Jamais d'apostrophe :
- noms, verbes (sauf -ri, -ti et -za ci-dessus), adjectifs, adverbes comme cane, ubu, nyene ;
- Nguyo, Ngiki : "Nguyo Umwagazi w'intama", "Ngiki igitabo" (la voyelle du mot suivant reste) ;
- kurubu quand il veut dire "peut-être" : Kurubu yaje, simbizi. Mais kur' ubu (à ce moment) ;
- devant un nom propre, aucun de ces mots ne s'élide, sauf devant Imana, Abarundi, Abanyarwanda... (pas vus comme noms propres).

Règle 4. nuko / n'uko :
- n'uko = ni uko : "Igituma atabikoze n'ukw atabimenye" (s'il ne l'a pas fait, c'est qu'il ne savait pas) ;
- n'uko = na uko : "Vyatewe n'uko ntariho" (c'est arrivé parce que je n'étais pas là) ;
- nuko (donc, alors) sans apostrophe : "Nuko rer' umuntu wese iy' ari muri Kristo..."

Règle 5. Suffixes -ho, -ko, -yo, -mwo, -na :
- -ko -> kw devant a et i : Yashizekw inkwi ; -> k' devant u : Yashizek' umunyu.
- -ho -> h' (devant toute voyelle) : Harih' ibitabo. Harih' abantu. Harih' umunyu. (On n'écrit pas hw.)
- -yo -> y' : Yashubijey' ibintu.  -mwo -> mw' : Yashizemw' ibintu.
- -na : jamais d'apostrophe : Baravugana ibikorwa.

Règle 6. Orthographe de certains mots :
- nta bwo, nta ho : deux mots, sans apostrophe (pas ntabwo).
- ba se, ba nyina, ba Bwana, ba naka, ba nde : deux mots.
- bene Data : deux mots, majuscule seulement à Data.
- Ntibaribwashike (temps "jamais encore") : un seul mot.
- amafaranga (pas amafranga), Afirika (pas Afrika), Igifaransa (pas Igifransa).
- avec pf : gupfa, gupfungana, urupfunguzo, impfunguzo, gupfunga, umupfuko, impfizi, gupfuka, gupfuma, ipfa, ipfupfu, amapfa, gupfinda.
- avec f seul : kwifuza, ifuku, ifuhe, gufukira, gufudika.

Règle 7. Majuscules : pas pour les mots qui désignent Dieu (yo, yera), sauf les noms : Imana, Rurema, Indavyi. Pas pour abera, abazungu, abirabura ; oui pour les peuples : Abarundi, Ababiligi, Abanyafirika. Igitabo c'Imana (la Bible) prend la majuscule.

Règle 8. mu et ku deviennent muri, kuri devant un nom propre ; devant une voyelle ils ne s'élident pas : muri Amerika, muri Afirika, muri Efeso, muri Egiputa.

Règle 9. Guillemets : -ti (ou ngo) sert déjà de guillemets. On ajoute des guillemets seulement si la fin de la citation n'est pas claire : Bat' "Abantu baje," baraheza baragenda.

Règle 10. y entre i et a : Mariya, Nehemiya, Eliya.

Règle 11. Mots venus du français : ikomine (commune), Leta (l'État), imiliyoni, istasiyoni, ilitiri, imisiyoni, ikilometero (pl. ibi-), umumisiyoneri, Amerika, igarame (pl. ama-), Ubwongereza (Angleterre), Abongereza (les Anglais), Icongereza (l'anglais), Abaprotestanti, Ministre mukuru (Premier ministre).

### R3. Règles tirées du vocabulaire
- Les mots du lexique sont rangés par racine. Il faut connaître les changements de sons : indwara est rangé sous r (n + r -> nd) ; beaucoup de mots en p sont sous h (n + h -> mp : impongo, impene) ; un nom de classe in- devant voyelle peut s'écrire avec y ou z (inyama, inzu) mais est rangé sous la voyelle.
- Le livre donne le perfectif entre parenthèses : gukora (ze) -> koze ; kwiga (ze) -> ize ; kurya (riye) ; kuja (giye) ; kuva (vuye) ; gupfa (fuye) ; gusha (hiye) ; kunywa (nyoye) ; guha (haye) ; kwumva (vise) ; kwuzuza (ujuje) ; kwoza (geje) ; kwotsa (okeje).
- Paires de sens par la longueur ou le ton (même écriture ou presque) : kubaza (demander) / kubāza (raboter) ; guhora (être calme, faire toujours) / guhōra (venger) ; guharura (gratter) / guharūra (compter) ; gukura (grandir) / gukūra (enlever) ; gusiga (laisser) / gusīga (oindre) ; gushira (finir / mettre) / gushīra (porter à) ; kurongora (épouser) / kurōngōra (conduire) ; isoko (marché) / isōko (source) ; inkoko (poule) / inkōko (corbeille) ; impera (fin) / impēra (récompense) ; umuryango (porte / famille).
- Classes irrégulières signalées : isaha (horloge, souvent cl. 3 : isaha), isahane et isandugu (cl. 9 au sg, cl. 10 ou 6 au pl selon le livre "3rd sg., 5th pl."), isazi, isi (classe "3rd" = cl. 9 dans la numérotation du Livre I), umucungwe (pl. 2 ou 5), umusore (pl. aba- ou imi-), urukaratasi (parfois 2 ou 4).
  Attention : la numérotation des classes du Livre I n'est PAS celle de nos générateurs (ici "1st" = classe des personnes umu-/aba- ; "3rd" = in-/in- ; "5th" = i-/ama-, etc. ; voir l'index : Class 9 = par. 62, Class 10 = par. 65). Il faut convertir avant de réutiliser les mentions "(5th)".
- -nzinya (tout petit) s'emploie seulement avec la classe "7th" du livre (aka-, diminutif).

## b) Comparaison avec nos générateurs

Conjugaison (gen_conjugaison_rn.py) :

| Règle à nous | Verdict | Preuve (annexe, tableau des temps) |
|---|---|---|
| présent -ra- : ndakora... barakora | CONFIRMÉE | "ndakora, urakora, arakora, turakora, murakora, barakora" |
| présent sans -ra- : nkora, ukora, akora, dukora, mukora, bakora | CONFIRMÉE | "Habitual Present : nkora ... dukora ... bakora". Le livre l'appelle présent HABITUEL. Notre étiquette "présent sans -ra-" est juste mais le sens "d'habitude" manque. |
| futur -zo- : nzokora... | CONFIRMÉE | "nzokora, uzokora, azokora, tuzokora, muzokora, bazokora" ; le livre précise "demain et après". Notre "Ejo" + futur est donc bon. |
| passé -a- + perfectif : nakoze... bakoze | CONFIRMÉE mais INCOMPLÈTE | Le livre a DEUX temps écrits pareil (aujourd'hui / hier), séparés par le ton. Le passé lointain sans -ra- s'emploie "si rien ne suit le verbe, dans les subordonnées et au négatif". |
| passé avec -ra- : narakoze... | CONFIRMÉE, sens à préciser | "narakoze, warakoze, yarakoze, twarakoze, mwarakoze, barakoze" = passé LOINTAIN (hier et avant). Ne pas l'utiliser pour "aujourd'hui". |
| "parfait" nkoze, ukoze... (sans -a-) | INCOMPLÈTE / à revoir | Ce temps n'est pas dans le tableau. Le tableau a à la place le passé IMMÉDIAT ndakoze, urakoze, arakoze, turakoze, murakoze, barakoze ("je viens de travailler"). Nos formes nkoze, dukoze ne s'emploient seules qu'en subordonnée ou relative ; ne pas les produire comme phrases simples traduites "j'ai travaillé". |
| négatif présent sinkora, ntukora, ntakora, ntidukora, ntimukora, ntibakora | CONFIRMÉE | identique au tableau. |
| négatif passé / futur | non montré | pas dans le tableau (rien contre). |
| sons n+b->mb, n+h->mp, n+r->nd | CONFIRMÉE | Préface du lexique : "indwara will be found in the r's", "many words with p will be found under h". |
| devant voyelle -ra- perd son a (ndiga) | non montré ici | pas de contre-exemple. |
| loi de Dahl tu->du | CONFIRMÉE | dukora, ntidukora (mais turakora, tuzokora, turiko : pas de Dahl devant r ou z). |

Accords (gen_accords_rn.py), d'après les exemples des règles d'orthographe :
- Démonstratif "ce...là" de la classe 1 (umuntu) : nos tables disent "uwo". Le livre écrit "Uyo arakora" (règle 2a) et "Kur' uyo" (règle 1a) ; et "N'ico uyu akoze". Donc classe 1 = uyu / UYO. Notre "uwo" pour la classe 1 est FAUX selon ce livre (uwo est la forme de la classe 3). C'est l'erreur la plus importante trouvée ici.
- Classe 7 "ico" : CONFIRMÉE (Nta co ukoze, Har' ico ubona?, N'ico uyu akoze kizovuga). Classe 8 "ivyo" : CONFIRMÉE (Kubw' ivyo, n'ivyo abishura). Classe 9 "iyo" : CONFIRMÉE (Mur' iyo nzu). Classe 9 "iyi" : CONFIRMÉE (Iyi irarwaye).
- Après un démonstratif le nom perd sa voyelle initiale : CONFIRMÉ (iyo nzu, iki gihe : "ab' iki gihe").
- Particule "de" + voyelle : s'élide (w'intama, c'Imana, ivy' abantu) : règle à AJOUTER à nos générateurs (on écrit sans doute "wa intama").
- Questions ouvertes : "iro/iryo" (cl. 5) et "uwu/uyu" (cl. 3) ne sont pas tranchées dans ma partie. Pour cl. 3, la forme "uwu" n'apparaît nulle part dans ma partie.
- Questions ouvertes "ndya", "mva", "mpfa" : le lexique donne kurya (riye), kuva (vuye), gupfa (fuye) mais pas les formes conjuguées. n + pfa : le livre classe "impfunguzo, impfizi" avec mpf, ce qui va dans le sens de "mpfa", sans le prouver.

Ce que nos générateurs ne savent PAS faire et que l'annexe enseigne (règle exacte) :
1. Passé immédiat : sujet + ra + perfectif (ndakoze, turakoze). Sens "je viens de".
2. Présent continu : sujet+ri+ko puis sujet+ra+racine (ndiko ndakora ; urik' urakora ; arikw' arakora ; turiko turakora ; muriko murakora ; bariko barakora).
3. Présent "encore" : sujet + raca + racine (ndacakora, turacakora).
4. Futur immédiat : sujet + ribu + racine + e (ndibukore, uribukore, aribukore, turibukore, muribukore, baribukore). Attention n + ri -> ndi.
5. "Pas encore" : négation + sujet + ra + racine (sindakora, nturakora, ntarakora, ntiturakora, ntimurakora, ntibarakora). Ne pas confondre avec le présent négatif.
6. Impératif : kora / mukore / ni mukore ; négatif : ntukore, ntimukore, ntibakore (+ ntakora/ntakore à vérifier).
7. Temps "jamais encore" : Ntibaribwashike (un seul mot).
8. Élisions et apostrophes (règles 1 à 5 ci-dessus) : à appliquer quand on colle les phrases générées (na + umuntu -> n'umuntu ; ariko + umuntu -> arik' umuntu ; kuko + afise -> kukw afise) et à NE PAS appliquer aux pronoms (Ni we azogenda, Uyo arakora).

## c) Pièges de traduction français <-> kirundi

- Deux passés écrits pareil : "nakoze" peut être "aujourd'hui" ou "hier", seul le ton change. Sans contexte, traduire par le passé composé français ; si "ejo" est présent, c'est hier. "narakoze" = hier ou avant, jamais "je viens de".
- "ndakoze" n'est pas un présent : c'est "je viens de travailler". "Urakoze" (tu viens de travailler) est devenu "merci".
- "ndakora" (avec -ra-) se dit quand rien ne suit ou pour insister ; "nkora" (sans -ra-) quand un complément suit et pour l'habitude. Ne pas traduire "nkora" par "je suis en train de".
- "Je suis en train de" = ndiko ndakora (deux mots).
- "Pas encore" = sindakora ; "pas" = sinkora : une seule syllabe -ra- change tout le sens.
- -ti / ngo ne se traduisent pas : ce sont des guillemets ("At' Uzoza ryari?" = Il dit : « Quand viendras-tu ? »).
- ejo = hier OU demain : c'est le temps du verbe qui tranche (ejo nakoze / ejo nzokora).
- kera = il y a longtemps OU dans longtemps.
- kugura = acheter ET vendre ; kugurana = emprunter OU prêter de l'argent ; gutira (emprunter un objet à rendre) / gutiza (prêter un objet).
- gusubira = retourner là d'où on vient ; kugaruka = revenir là où est celui qui parle.
- data / dawe = mon père ; so = ton père ; se = son père ; mama / mawe = ma mère ; nyoko = ta mère ; nyina = sa mère. Le possessif est dans le mot : ne pas ajouter "wanje".
- mushiki = soeur d'un garçon ; musaza = frère d'une fille ; mukuru / murumuna = aîné / cadet du même sexe.
- kurongora (épouser, dit de l'homme) ; pour la femme on emploie le passif.
- umuryango = porte OU famille (ton différent).
- n'uko = "c'est que" (ni uko) ou "par le fait que" (na uko) ; nuko = donc.
- Pronom objet : "Igituma atabikoze" : -bi- (classe 8) = "le, cela" ; en français on dit "il ne l'a pas fait".
- -ri vs ni : -ri = être (lieu, état : Ar' i muhira "il est à la maison") ; ni = c'est (Ni we "c'est lui").
- Faux amis venus du français : Leta = l'État ; ikomine = la commune ; Ministre mukuru = Premier ministre.
