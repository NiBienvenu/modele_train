# Notes partie 3a : Livre I, leçons 82 à 124

ATTENTION AUX NUMÉROS DE CLASSE. Le livre numérote les classes par paires (sing./plur.).
Correspondance avec la numérotation de nos générateurs (Meinhof) :
- livre 1 = 1/2 (umu-/aba-) ; livre 2 = 3/4 (umu-/imi-) ; livre 3 = 9/10 (in-/in-)
- livre 4 = 7/8 (iki-/ibi-) ; livre 5 = 5/6 (i-/ama-) ; livre 6 = 11/10 (uru-/in-)
- livre 7 = 12/13 (aka-/utu-) ; livre 8 = 14/6 (ubu-/ama-) ; livre 9 = 15/6 (uku-/ama-) ; livre 10 = 16 (aha-)
Dans ces notes, j'utilise NOS numéros.

## a) Règles de grammaire

### R1. Adverbe -rtya / -rtyo (comme ceci / comme cela) (L82, par. 163)
- Prend le préfixe sujet du verbe qu'il suit : yabikoze **artya**, babikoze **bartyo**, tugire **durtya** (Dahl : tu -> du).
- Après un infinitif : **gu**rtya / **gu**rtyo : tugomba kuririmba gurtyo = nous voulons chanter comme cela.
- 1re pers. sing. : pas de r : Ndakora **ntya** = je fais comme ceci.
- Ne s'emploie pas pour « faire comme Jean ».

### R2. Passif : -w- avant le -a final (L83, par. 164-165)
- gukunda -> gukundw**a** (être aimé), kubona -> kubonwa.
- Après b, le w devient g à l'écrit du livre : kurab**w**a (le livre écrit « kurabwa » mais dit « w changé en g » ; à vérifier).
- « par » = na : Turakundwa n’Imana = nous sommes aimés de Dieu.

### R3. Passé du passif (L84, par. 167-168)
- Règle générale : passé actif + w : yakunze -> yakun**zwe**, yaboshe -> yabo**shwe**.
- Exceptions :
  - -ma / -mye -> -mwe (pas de y) : yavomye -> yavo**mwe**.
  - passif en -rwa : actif -ye -> -we (yatwaye -> yatwa**we**) ; -ereye / -iriye -> -erewe / -iriwe (yasubiriwe, yaremerewe) ; -ze -> -zwe (yagize -> yagizwe).
  - kugaya -> kugawa, passé yagawe.
  - -nnye -> -nnywe : yamennye -> yamennywe.
  - -ba -> -bwe : yahembwe (il a été payé).

### R4. Passif des verbes d'une syllabe : -bwa / passé -we (L85, par. 169-171)
| infinitif | passif présent | passé passif |
|---|---|---|
| guca | gucibwa | yaciwe |
| kugwa | kugubwa | yaguwe |
| guha | guhabwa | yahawe |
| kunywa | kunyobwa | yanyowe |
| gusya | gusebwa | yasewe |
| guta | gutabwa | yatawe |
| kuva | kuvubwa | yavuwe |
| kurya | kuribwa | yariwe |
- guhabwa = recevoir : nahawe igitabo = j'ai reçu un livre (pas « le livre m'a été donné »). Sert aussi de futur de -fise.

### R5. Démonstratifs (L86-88, par. 172-180)
Formes (NOS classes) : ceci / cela (proche ou déjà dit) / là-bas / très loin / celui qu'on connaît / (uno)
- 1 uyu, uwo, urya, uriya, wa, uno ; 2 aba, abo, barya, bariya, ba, bano
- 3 **uyu**, uwo, urya, uriya, wa, uno ; 4 iyi, iyo, irya, iriya, ya, ino
- 5 iri, **iryo**, rirya, ririya, rya, rino ; 6 aya, ayo, arya, ariya, ya, ano
- 7 iki, ico, kirya, kiriya, ca, kino ; 8 ibi, ivyo, birya, biriya, vya, bino
- 9 iyi, iyo, irya, iriya, ya, ino ; 10 izi, izo, zirya, ziriya, za, zino
- 11 uru, urwo, rurya, ruriya, rwa, runo ; 12 aka, ako, karya, kariya, ka, kano ; 13 utu, utwo, turya, turiya, twa, tuno
- 14 ubu, ubwo, burya, buriya, bwa, buno ; 15 uku, ukwo, kurya, kuriya, kwa, kuno ; 16 aha, aho, harya, hariya, ha, hano
- Formation : « ceci » = voyelle initiale + préfixe verbal (y entre deux voyelles) ; « cela » = voyelle initiale + particule possessive avec a -> o ; « là-bas » = préfixe verbal + -rya (cl. 1 : u-) ; « très loin » = -riya (i allongé si c'est plus loin).
- wa/ca/... (= particule possessive placée AVANT le nom) : chose connue des deux : wa mukobwa = cette fille (dont on a parlé).
- uwo = déjà mentionné ; uyu = pas encore mentionné : ayo majambo / aya majambo.
- Le démonstratif précède le nom, qui perd sa voyelle initiale : aba bagabo. mu/ku -> mur’/kur’ : mur’ abo bantu = parmi ces gens.
- nya (invariable, surtout singulier) ~ uwo : nya muntu.
- Pronom démonstratif = même forme, seul : N’ibi? Oya, s’ivyo. (L93, par. 190)

### R6. Temps « pas encore » : NEG + sujet + -rā- + radical présent (L89, par. 183)
- Sindāgenda = je ne suis pas encore parti ; Ntarāgenda ; Ntituragenda.
- Verbe à voyelle : le a tombe : ntarōza amasahane ; ntiturubaka.
- Affirmatif en question : Mbeg’ arāgenda? = est-il déjà parti ?
- Garde -ra- même en proposition dépendante (par. 184).

### R7. Propositions dépendantes (L91, par. 184-187)
- Pas de -ra- (présent, passé -ra-, -ara-) dans une dépendante (après kuko, yuko, ko, relatives). Exceptions : futur proche et « pas encore » gardent -ra-.
- Après kuko/yuko/ko, « être » à la 3e personne = **ari** pour TOUTES les classes (sauf si un mot de lieu suit) : kukw ari mbi (pas iri mbi).
- Négation dépendante : sujet + **-ta-** : (kuko) ntagenda, utagenda, atagenda, tutagenda, mutagenda, batagenda.
  - Pas de loi de Dahl sur la syllabe avant -ta- (tutagenda, pas dutagenda), mais -ta- lui-même la subit : ba**da**saba, a**da**fise, ka**da**fata, tu**da**komeye.
  - Passé : batāgiye, batākinnye, batūbatse ; voyelle : kukw atihannye.
  - Être : ntari, utari, atari...
  - Après kugira ngo : négation NORMALE : kugira ngo ntibamufate.

### R8. « Avant que » = dépendant + -ta-ra- (L92, par. 188-189)
- Zana inkwi utaragenda = apporte du bois avant de partir. Pas de mot pour « avant ».

### R9. -kwiye et -rinda (obligation) (L93, par. 191)
- akwiye kugenda = il doit partir. Négatif : Ntakwiye kugenda = il ne doit pas partir ; Ntarinda kugenda = il n'est pas obligé de partir.
- -kwiye = suffire : birakwiye = il y en a assez ; Bose ntibakwiwe = pas assez pour tous. = mériter : Sinkwiye...
- -kwiye n'existe qu'à cette forme ; -rinda à tous les temps.

### R10. Relatives (L94-95, par. 192-196)
- Aucun mot pour « qui/que » ; verbe dépendant (sans -ra-, négation -ta-), intonation spéciale.
  Abantu bakunda Imana bayikurikira neza ; Abahungu bataje mw ishuli bazohanwa ; Umuntu nahamagaye araza.
- Sans antécédent : sing. **ū-** (uw- devant voyelle), passé uw-a- ; plur. aba- : uwiba (celui qui vole), uwabonye, abazoza. Pour une chose : voyelle initiale + préfixe : ikitubuza.
- Antécédent pronom objet : démonstratif : Abo nkunda ; ico igomba.
- Antécédent 1re/2e personne : le verbe relatif reste à la 3e : twebwe abakora...

### R11. nde ? (qui ?) (L96, par. 197)
- Pluriel ba nde. Uri nde? Ni nde yasohotse? (sujet : ni nde + relatif). Objet : après le verbe : Wabonye nde? Witwa nde? = comment t'appelles-tu ?
- « à qui ? » : n’ica nde? n’iza ba nde? (pronom possessif = voyelle initiale + particule : uwa, ica, iya...). Après préposition : ku -> kwa : Tugende kwa nde?
- nde vient après la relative : Umuntu nabonye ni nde?

### R12. -he ? (lequel ?) (L97, par. 198-199)
- 1 uwuhe/abahe ; 3 uwuhe/iyihe ; 9 iyihe/izihe ; 7 ikihe/ibihe ; 5 irihe/ayahe ; 11 uruhe ; 12 akahe/utuhe ; 14 ubuhe ; 15 ukuhe.
- Avant le nom (nom sans voyelle initiale) ou après (en dernier) : ikihe gitabo ; umusi uwuhe ; inka zawe nini izihe.
- Pas de loi de Dahl (ikihe, akahe : syllabe longue accentuée).

### R13. Forme applicative (prépositionnelle) -ira / -era (L98-99, par. 200-204)
- -a -> -ira / -era selon la règle A I U (harmonie vocalique) : kuzanira, gukorera.
- -za -> -riza/-reza (gukiriza, kubariza) ; -sha -> -shiriza/-shereza (gushuhiriza, gukoreshereza).
- Passé : -iye/-eye (yandikiye, yakoreye) ; -za -> -je (yambarije).
- Monosyllabiques : kubera, gucīra, kugwīra, guhēra, kunywēra, gupfīra, guhīra, gusēra, gutēra, kuvīra, kurīra, kuzīra.
- Usages : « à, pour » (Nzomugurira igitabo) ; temps incertain après aho/igihe (Sinzi aho nzogarukira ; Sinzi igihe yapfiriye) ; lieu (Tuzoshimira Imana mw ijuru).
- Pas avec les verbes de mouvement pour « vers » : Yirutse i muhira.

### R14. Réfléchi : i- (iy- devant voyelle) devant le radical (L103, par. 208-210)
- kwikunda, kwiyigisha ; devient un verbe à voyelle ; kwigurira igitabo (s'acheter). Impératif en -e : Ikize!

### R15. Nta (aucun, personne) (L104-105, par. 211-216)
- nta + nom sans voyelle initiale + relative : Nta muntu yaje ; Nta gitabo mfise.
- Pronom : nta wu- / nta w- : Nta wugomba kugenda ; Nta wanka...
- Nta n’umwe = pas même un ; question « quelqu'un ? » : Nta wabonye igitabo canje?
- Objet : toujours AVANT le verbe : Nta biti nabonye.
- nta + pronom : Nta we, Nta bo, Nta zo mfise, Nta yo, Nta co (= rien) ; Nta co urira! = arrête de pleurer ; Nta ho = jamais / nulle part (Nta ho urāsoma...?).
- Dépendant : ata : kukw ata mafaranga afise.

### R16. Réciproque / associatif -na (-nya) (L106-107, par. 217-221)
- gukundana (s'aimer), kubonana ; gufashanya, kwigishanya. Passé -nye / -nije : Bakundanye, Bafashanije.
- Seulement verbes transitifs ; pas d'autre objet en général (sauf avec applicatif : kwandikirana ivyete ; kugiriranira ishari).
- Associatif (ensemble) : gukorana n’abandi. PIÈGE : turirimbane = chanter l'un de l'autre ; « chantons ensemble » = turirimbe/turirimbire hamwe. gusengana = s'adorer l'un l'autre ; prier ensemble = gusengera hamwe.
- kujana : Petero ajana abana (emmène) / Abana bajana na Petero (vont avec).

### R17. -te ? (comment ?) et comparaison (L108, par. 223-224)
- Préfixe sujet : nte, ute, ate, dute, mute, bate ; cl. 7 gite, 8 bite, 16 hate...
- ameze ate? = comment va-t-il ? ; tugire dute? = que faire ? ; bigende bite?
- Comparatif : kuruta (statif / adjectif), kurusha (verbe d'action), gusumba : ni munini kuruta uyo ; aririmba neza kurusha Petero.

### R18. « Pourquoi ? » (L109, par. 225)
- Seul : Ni ku ki? ; présent/futur : N’iki gituma (gitumye) + verbe ; passé récent : N’iki gitumye ukubise (sans -ra-) ; passé : N’iki catumye ukubita (verbe au présent !).
- Négatif : N’iki catumye udakora? ou mieux N’iki cakubujije gukora?
- Applicatif + iki : U(n)yankira iki? = pourquoi me hais-tu ?

### R19. « Quelques » et distributif (L111, par. 226-227)
- Souvent rien : Mbeg’ ufise ibijumbu? ; partie d'un groupe : bamwe, bimwe (bamwe-bamwe) ; rimwe-rimwe = parfois ; hamwe-hamwe = ici et là.
- abiri-abiri = deux chacun ; umwe-umwe = un par un.

### R20. Conditionnel : sujet + o + radical (L111, par. 228)
- nokunda, wokunda, yokunda, twokunda, mwokunda, bokunda.
- Verbe à voyelle : infinitif complet : mwokwemera.
- Négatif : sinokunda, ntiyokunda, ntiyokwemera.
- Avec namba (si) : Namb’ ufise umwanya, woshobora kuruhuka.

### R21. Adjectifs exprimés par des verbes (statifs) (L112, par. 229)
- Épithète = relatif, sans -ra- : umugabo akomeye ; impuzu zikanye ; umwana asinziriye (endormi).
- Attribut : statif avec -ra- : inzira irapfunganye. Négatif et dépendant : sans -ra-.

### R22. Verbes redoublés (L113, par. 230)
- kugendagenda, guhendahenda, gukorakora, kumaramara, kuvangavanga ; passé sur la 2e partie seulement : yagendagenze, yakorakoye, isi yanyiganyize.

### R23. Discours direct / indirect (L114, par. 231-232)
- -ti + paroles exactes ; préfixe sujet : nti, uti, ati, kiti (pas de loi de Dahl) : Yavuze, ati ...
- Indirect : yuko/ko + verbe dépendant ; ngo pour les deux.

### R24. Suffixes locatifs -ho, -ko, -yo, -mwo (L115, par. 233-236)
- -ho : kubaho (exister), Harih’ ibitabo?, gukuraho.
- -ko (= ku) : nagishizeko ; -yo (= là, lieu déjà cité) : Nzosubirayo ; -mwo (= mu) : Sukamw’ amazi ; -rimwo = contenir.
- Ne changent pas le verbe ; o -> w devant voyelle.

### R25. ki / umuki / n’iki (L116, par. 237-239)
- N + ki (étonnement, après le nom) ; n’umuki (nationalité, sorte ; préfixe nominal : uruki, igiki...) ; n’iki? = quoi ?
- Salutation : N’amaki? -> N’amahoro / N’amarembe.

### R26. Temps -ka- (consécutif) (L117, par. 240)
- Relie des actions qui se suivent : Atera imbuto zikamera zigakura zikama ivyamwa. Subit la loi de Dahl (ga). Prend le temps et le mode du premier verbe. Aussi narratif et habitudes.

### R27. Temps -raca- (encore) (L118, par. 243)
- ndacakora, uracakora, aracakora, turacakora, muracakora, baracakora ; aracari hano.
- Négatif et dépendant : -ki- (Dahl : gi ; devant voyelle c) : ntakīza = il ne vient plus ; ntaciga = il n'étudie plus.
- Dépendant = « pendant que » : Akirima avugana n’abandi.

### R28. Adverbes de lieu + ya (L118-119, par. 242-245)
- hepfo ... hanze + **ya** + nom (imbere y’umuhungu) ; avec pronom : possessif (inyuma yiwe). hanyuma y’ivyo. i buryo bwiwe ; i ruhande y’inzira.
- imbere / inyuma : sens souvent inverse du nôtre (imbere = plus à l'intérieur).

### R29. Divers (L102, 120-121)
- kuja (lieu précis) / kugenda (sans lieu) ; ntuze / intuze / naka ; kubwa + possessif : kubwanje, kubwacu.
- umunya- (umunye-) + nom = personne caractérisée : umunyeshuli, umunyabwenge, umunyantege nke (cl. 1, adjectif accordé au nom interne).
- Nom + particule + nom : umusezi w’impumyi.
- -nyene : jenyene, wenyene, twenyene, mwenyene, bonyene, ryonyene, conyene ; ubwanje (moi-même de mes mains).
- na/nka + pronom : nanje, nawe, na we, natwe, namwe, na bo ; nkanje... ; gusa na (ressembler, pas de passé), bene (comme, apparence), nka (action).

### R30. Récit (L123-124, par. 253-254)
- Verbe principal au présent -ra- si rien ne suit (sauf cane, ati) ; sinon présent sans -ra- (aussi avant un infinitif). Avant ngo/yuko : -ra-.
  Umugabo abona ingwe aratinya arahunga ; ashika mu nzu arihisha.
- Dépendante dans le récit : « parfait » sans -a- (avuye = en sortant).
- Trait de caractère : préfixe passé + radical présent : yakunda gukora.
- Négatif narratif : sinabona, ntiwabona, ntiyabona, ntitwabona, ntimwabona, ntibabona (passé + radical PRÉSENT).

### R31. Tableau des temps (L122, par. 252)
- -ra- présent aragenda / neg ntagenda ; continu arikw aragenda ; sans -ra- agenda.
- passé immédiat aragiye ; passé yagiye ; passé -ara- yaragiye ; négatif des trois : ntiyagiye.
- futur azogenda, azokwereka ; -ka- akagenda ; pas encore ntaragenda ; -raca- aracagenda / ntakigenda ; conditionnel yogenda / ntiyogenda / yokwereka.
- Voyelle : arereka, yereka, ntiyereka, areretse, yeretse.

Ce que nos générateurs ne savent PAS faire et que cette partie enseigne :
1. Négation dépendante -ta- (+ Dahl -da-) et -ta-ra- (« avant que »).
2. Temps « pas encore » : sindāgenda, ntarāgenda, ntituragenda, ntarōza.
3. Conditionnel : nokunda... bokunda, sinokunda, mwokwemera.
4. Temps -raca- : ndacakora ; négatif ntakigenda / ntaciga.
5. Temps -ka- consécutif (akagenda, zikamera, zigakura).
6. Négatif narratif sinabona (passé + radical présent) et trait de caractère yakunda.
7. Passif (-w-, -bwa pour monosyllabiques, passés irréguliers) ; applicatif -ira/-era (passé -iye/-eye, -je) ; réfléchi i-/iy- ; réciproque -na (passé -nye/-nije) ; redoublement.
8. Relatives (ū-/uw-, aba-, sans -ra-), nta, nde, -he, -te, -rtya.
9. Démonstratifs urya/uriya/wa et classes 15/16 (uku, ukwo ; aha, aho).
10. Suffixes -ho, -ko, -yo, -mwo.
11. Après kuko/ko/yuko, « être » 3e personne = ari pour toutes les classes.

Réponses aux questions ouvertes : « uyu muduga » (cl. 3), « iryo » (cl. 5). Les autres (narize, ndya, mva, mpfa) ne sont pas traitées ici.

## c) Pièges de traduction

- **ntagenda** a deux sens : principal = « il ne part pas » ; après kuko = « je ne pars pas » (n + ta). Lire le contexte.
- **Pronoms objets** : Bamwise (-mu- lui), nagishizeko (-gi- = igitabo), Nta zo mfise (zo = inka), uyivemwo (yi = inzu). Toujours reprendre le nom déjà cité au bon nombre et à la bonne classe.
- **Pas de « qui/que »** en kirundi : un verbe sans -ra- juste après un nom est souvent une relative. Ne pas traduire comme deux phrases.
- **Pas de mot pour « avant »** : -ta-ra- (utaragenda = avant que tu partes).
- **N’iki catumye ukubita** : le verbe après catumye reste au présent mais le sens est passé.
- **Récit** : le présent kirundi (abona, aratinya) se traduit au passé en français.
- **kwita ≠ guhamagara** : nommer / appeler (faire venir).
- **guhabwa** = recevoir (nahawe igitabo = j'ai reçu un livre).
- **-kwiye / -rinda** au négatif : ntakwiye = ne doit pas ; ntarinda = n'est pas obligé.
- **turirimbane** ≠ chantons ensemble (= turirimbe hamwe) ; gusengana ≠ prier ensemble.
- **gukena** = ne pas avoir du tout (pas « vouloir »).
- **umwanya** (moment, place) ≠ **igihe** (temps en jours, années).
- **imbere / inyuma** : souvent l'inverse de « devant / derrière ».
- **ejo** = hier ou demain (temps du verbe décide) ; hirya y'ejo = avant-hier ou après-demain.
- **isoko** (marché) / **isōko** (source) ; **umuryango** famille / porte ; **inda** ventre / pou ; **gusiga** laisser / **gusīga** oindre ; kubarira (raconter) / kubarīra (coudre) ; kurinda (devoir) / kurinda (garder).
- **Navunitse ukuboko** = je me suis cassé le bras (intransitif, pas transitif sauf si exprès).
- **Ndananiwe** = je n'y arrive pas (pas seulement « je suis fatigué »).
- **Nta co urira!** = arrête de pleurer (impératif d'arrêt), pas « tu ne pleures rien ».
- **Nta ho** = jamais / nulle part.
- **inkuba yakubise umuntu** = la foudre a frappé (pas umuravyo).
- **gusa** : seulement / vide / nu (adverbe) et ressembler (verbe + na).
- **Ntazobura kugenda** = il ira sûrement (double négation).
- Erreurs probables du livre gardées telles quelles (marquées « à vérifier ») : Uyankira iki ? (Unyankira ?), Yabokize na we (Yabikoze ?), Twakukwekw ivyaha, anglais « whom did I see » pour Wabonye nde, « does not » pour akora ico igomba.
