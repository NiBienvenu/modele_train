Dans ces notes, je donne d'abord la classe Cox, puis la nôtre entre crochets.

## a) Règles de grammaire

### R1. Classe 1/2 : umu-/aba- (leçon 1, par. 2)
Noms de personnes. Accord du verbe : a- (sing.), ba- (plur.). Le sujet peut manquer quand on sait de qui on parle.
- Umugabo arakora. = L'homme travaille.
- Baragenda. = Ils s'en vont.
Pas d'article en kirundi (« un », « le » n'existent pas).

### R2. Changements de voyelles (leçons 2, 5, 9, 14 ; par. 3, 9, 16, 22)
- u + voyelle -> w : umu-ana = umwana (et la voyelle suivante devient longue : umwīgisha).
- a + voyelle -> a disparaît : aba-ana = abāna, aba-igisha = abīgisha.
- Exception : a + i -> e devant -iza et -inshi : ba-iza = beza, ma-iza = meza, ama-inyo = amenyo.
- i + voyelle -> y (souvent) : imi-enda = imyenda, mi-iza = myiza.
- ki + voyelle -> c ; bi + voyelle -> vy : iki-ete = icete, ibi-aha = ivyaha, ki-iza = ciza, bi-iza = vyiza.
- Au verbe à voyelle : a + i -> yi (a ne tombe pas) : a-izera = yizera, yandika, yereka (par. 71).

### R3. Ni / Si (leçon 2, par. 4)
ni = « est / sont », si = « n'est pas / ne sont pas », même forme pour tous les sujets. Le i tombe devant une voyelle (n', s') sauf devant un nom propre.
- N'umwami. = C'est le roi.
- Umugabo s'umwami. = L'homme n'est pas roi.
- Umwigisha ni Andereya. = L'enseignant est André.
Interdit : dans une subordonnée, ou suivi d'un lieu (on prend alors -ri). Exception : si le sujet est lui-même un lieu : Gitega ni kure. = Gitega est loin.

### R4. Possessifs (leçon 3, par. 5)
Préfixe accordé avec la chose possédée + suffixe du possesseur : -nje (moi), -we (toi), -iwe (lui/elle), -cu (nous), -nyu (vous), -bo (eux).
Contraction à la 3e pers. sing. : wa-iwe = wiwe, ba-iwe = biwe, ya-iwe = yiwe, za-iwe = ziwe, ca-iwe = ciwe, vya-iwe = vyiwe, rya-iwe = ryiwe.
- umwana wiwe = son enfant ; abana babo = leurs enfants ; inka zanje = mes vaches.
Le possessif suit le nom. Avec un adjectif, le possessif vient d'abord : inka ziwe nkeya = ses quelques vaches (par. 15).

### R5. Particule « de » (leçon 6, par. 12)
Même forme que le préfixe du possessif, accordée avec la chose possédée ; le a tombe devant voyelle.
- Umutima wa Yesu. = le cœur de Jésus. Imirima y'abantu = les jardins des gens. Abana b'umwigisha = les enfants de l'enseignant.

### R6. Na « et » (leçon 4, par. 8)
na relie des noms (pas des phrases ; pour des phrases : kandi). Une liste répète na : Umugabo n'umugore n'umwana. Élidé n' devant voyelle (même forme que ni élidé).

### R7. Mu / Ku (leçon 5 par. 10 ; leçon 18 par. 32)
mu = dans, hors de (l'intérieur) ; ku = sur, à, de (l'extérieur). Ils font tomber la voyelle initiale du nom : ku muriro, mu mwiza.
Exception classe 5 [5] au singulier : mw / kw et le nom garde sa voyelle : mw ishuli, kw ibuye, mw isahane (aussi isuka, isaho, isahane). Mais : mu zuba, mu zuru, mu jisho, mu ziko. Pluriel : toujours régulier (ku mabuye, mu maso).

### R8. -ra- tombe devant un complément (leçon 5 par. 11 ; leçon 16 par. 27 ; leçon 25 par. 44-45)
Présent en -ra- : quand rien ne suit, ou quand suit cane, neza, ati ; pour une habitude (même avec complément) ; jamais dans une subordonnée.
Présent sans -ra- : quand un complément suit et qu'on parle de maintenant ; obligatoire dans une subordonnée.
- Agenda mu mwiza. (pas aragenda mu mwiza) = Il marche dans le noir.
- Mbeg' Abarundi bararya inyama? = Les Barundi mangent-ils de la viande ? (habitude)
- Ukora iki? Nteka ibijumbu. = Que fais-tu ? Je cuis des patates douces.

### R9. Classe 2 [3/4] : umu-/imi- (leçon 4, par. 7)
Choses, pas des personnes. Sujet u-/i-, possessif wa-/ya-, adjectif mu-/mi-.
- umutwe wiwe = sa tête ; imitwe yabo = leurs têtes.

### R10. Classe 3 [9/10] : in-/in- (leçon 7, par. 13 ; leçon 11, par. 17)
Même forme au sing. et au pluriel. Sujet i-/zi-, possessif ya-/za-, adjectif nasal n-.
Certains mots n'ont que i- (ifi, ifu, isuka, isaho, isahane) ; isuka/isaho/isahane font le pluriel en ama- [6].

### R11. Règles du n (leçon 7, par. 14 ; leçon 9)
- n + b, m, v, f, p -> m (imbwa) ; n + h -> mp (impuzu = in-huzu) ; n + r -> nd (indimiro = in-rimiro, ndakora) ; n + n -> n ; n + voyelle -> nz (inzara, nziza). Imana = in-mana (le n tombe).
- Exception : n + inshi -> nyinshi.
- -nini ne prend pas de n en plus : inka nini.
- Verbe : n + f -> mf : mfise, simfise (par. 36).

### R12. Adjectifs (leçon 8, par. 15)
Préfixe du nom sans voyelle initiale ; ils suivent le nom. Une quinzaine seulement (-bi, -bisi, -gari, -gufi, -inshi, -iza, -ke, -kuru, -nini, -nzinya, -rere, -sa, -sha, -to, -toto, -zima). -rere répète le préfixe : muremure, birebire, ndende. Quantité en dernier : inka mbi nkeya. -nini et -to se redoublent au pluriel : abana bato-bato.
- umuntu mubi = une mauvaise personne ; imitima mibi = de mauvais cœurs.

### R13. Verbe -ri « être » (leçon 12, par. 19 ; leçon 17, par. 29)
Pour les lieux (où ni/si est interdit). ndi, uri, ari, turi, muri, bari ; classes : uri/iri, iri/ziri, kiri/biri, riri/ari, ruri/ziri, kari/turi, buri/ari, kuri/ari, hari. Pas d'infinitif : on prend kuba. Négatif : sindi, nturi, ntari, ntituri, ntimuri, ntibari.
- Umwana ar'i muhira. = L'enfant est à la maison.
- Impene zawe ziri hehe? = Où sont tes chèvres ? (hehe toujours à la fin)

### R14. Préposition i (leçon 11, par. 18)
i = à / de devant un nom de lieu : i Gitega. Aussi : i muhira (à la maison), i wacu (chez nous), i wanyu, i wabo. Le chef de l'enclos dit i wanje ; « chez lui » = i we (pas i wiwe).

### R15. Classe 4 [7/8] : iki-/ibi- (leçons 13-15, par. 20-25)
Sujet ki-/bi-, possessif ca-/vya-, adjectif ki-/bi-. Devant voyelle : c-/vy-.
Usages spéciaux :
- sujet double de classes différentes -> accord bi-/vy- : Umutsima n'inyama biri mu nzu. Deux personnes -> ba- : Umuhungu n'umukobwa barakora. Même classe -> la classe des noms (préféré) ou vy-.
- grande taille : igisozi (très grande colline), ikibuye, ikivura.
- « chose » indéfinie : ivyiza (les bonnes choses), ivyanje (mes affaires), Bizoba neza (ça ira bien).

### R16. Loi de Dahl (leçon 13, par. 21)
k -> g et t -> d dans un préfixe si la racine commence par c, f, h, k, p, s, t : igitabo, igiti, igihugu. Pas après une consonne (ntukora). Pas si la voyelle est longue (le livre cite atīhana ; exemple peu clair, à vérifier).
Aussi pour ku [15] : ukwizera guke, ni kugufi (pas de Dahl devant g).

### R17. Négatif du présent (leçon 17, par. 28)
nti- + sujet + racine (le -ra- doit tomber, sinon c'est le temps « pas encore »). 1re pers. : si-.
- sinkora, ntukora, ntakora, ntidukora, ntimukora, ntibakora. Classes : inka ntizigenda.

### R18. Classe 5 [5/6] : i(ri)-/ama- (leçons 18-19, par. 30-34)
Sujet ri-/a-, possessif rya-/ya-, adjectif ri-/ma- (ryiza, meza). Devant voyelle : ry- (iryinyo). Pluriels irréguliers : ijisho -> amaso, irigi -> amagi, iryinyo -> amenyo. Mots seulement au pluriel : amazi, amata, amavuta, amahoro, amaraso, ameza. icumu, ico, icukiro sont de cette classe (pas iki-).

### R19. Présent continu (leçon 19, par. 35)
-ri + ko + présent en -ra- : ndiko ndakora, urik' urakora, arikw arakora, turiko turakora, muriko murakora, bariko barakora. Négatif : sindiko ndakora, nturik' urakora, ntarikw arakora... Pas soumis aux règles du -ra- (garde -ra- même avec complément) : Arikw ararima mu murima wanje.

### R20. -fise « avoir » (leçon 21, par. 36)
Défectif (pas d'infinitif, pas d'impératif, pas de futur lointain) : on prend kugira. mfise, ufise, afise, dufise, mufise, bafise ; négatif simfise, ntufise, ntafise, ntidufise. ndafise rare, sans complément.

### R21. Infinitif et impératif (leçon 22, par. 37-38 ; leçon 28, par. 56)
Infinitif ku-/gu- (Dahl) + racine ; kw- devant voyelle. Impératif sing. = racine : Kora! Genda! Zana! Négatif : ntu- + racine, finale a -> e : Ntugende! Ntuteke! kuza n'a pas d'impératif : Ngwino / ngo.

### R22. Classe 6 [11/10] : uru-/in- (leçons 23-24, par. 39-43)
Sujet ru-/zi-, possessif rwa-/za-, adjectif ru-/n-. Pluriel en in- avec les règles du n : urubaho -> imbaho, urukwi -> inkwi. Racine à voyelle -> inz- : urugi -> inzugi, uruzi -> inzuzi, uruyuki -> inzuki, uruyoya -> inzoya, uruyige -> inzige, urwara -> inzara. Voyelle courte : on insère y (uru-uki = uruyuki) ; voyelle longue : w (urwāra). urushi -> amashi (paumes), inshi = gifles.

### R23. Classe 7 [12/13] : aka-/utu- (leçon 26, par. 46-49)
Sujet ka-/tu-, possessif ka-/twa-, adjectif ka-/tu- (ka-iza = keza). Diminutif de n'importe quel nom : akana (petit enfant), agakoko (insecte), agahuzu, akunyu (pas akanyu), utuzi, uduta. Sert à demander poliment : Ngomba agahuzu.

### R24. Classe 8 [14/6] : ubu-/ama- (leçons 27-28, par. 50-55)
Sujet bu-/a-, possessif bwa-/ya-, adjectif bu-/ma-. Surtout des noms abstraits (ubwenge, ubuntu, ubugingo, ubwana, ubusore, Ubukristo). Nombre précis : singulier (ubwato bubiri) ; nombre vague : pluriel (amato menshi). Expressions de temps : bwakeye, burije (bwije en subordonnée), bukeye, ubu.
kuko, ariko : ko -> kw devant a, e, i ; k' devant u (kukw ifise, arik' ubu).

### R25. Futur (leçon 29, par. 57 ; leçon 31, par. 60)
-zō- (long) = après aujourd'hui : nzogenda, uzogenda, azogenda, tuzogenda, muzogenda, bazogenda. Le futur du jour même = présent en -ra- : Ndagenda uyu musi. Ce -ra- reste même devant un complément et dans une subordonnée (affirmatif).
Négatif : sinzogenda, ntuzogenda, ntazogenda, ntituzogenda, ntimuzogenda, ntibazogenda. Interdit dans une subordonnée.
ejo = hier ou demain selon le temps.

### R26. Classe 9 [15] : uku-/ama- (leçon 32, par. 62-64)
Sujet ku-/a-, possessif kwa-/ya-, adjectif ku-/ma-. Tous les infinitifs ; nom verbal avec u- : ukwizera (foi), Ukugaruka kwiwe (son retour). Autres : ukuboko, ukuguru, ugutwi, ukwezi (pl. amezi), ukwaha, ukuri.

### R27. Classe 10 [16] : aha- (leçon 33, par. 65-67)
Seul nom : ahantu. ha- = idée de lieu : Hano ni neza ; Ni habi cane ; Hariya hitwa Gitega. Impersonnel : Harashushe (il fait chaud). « Il y a » : Haza umugabo ; Hariho ibijumbu? -> réponse accordée au nom : Ego, biriho / Nta biriho. « Visage » = mu maso hiwe. Pas de mu devant ahantu : ahantu heza = dans un bel endroit.

### R28. Verbes à voyelle (leçons 35-36, par. 69-74)
Racine à voyelle longue, infinitif kw-.
- présent -ra- : ndizera, urizera, arizera, turizera, murizera, barizera.
- présent sans -ra- : nizera, wizera, yizera, twizera, mwizera, bizera ; classes : wereka/yereka, yereka/zereka, cereka/vyereka, ryereka/yereka, rwereka/zereka, kereka/twereka, bwereka/yereka, kwereka/yereka, hereka.
- continu : ndiko ndigisha.
- futur : préfixe + zo + infinitif entier : nzokwandika, azokwibuka, bazokwubaka ; localement nzandika, azibuka.
- négatif futur : sinzokwibagira, ntazokwubaka, ntituzokwibagira.
- négatif présent : sinibuka, ntiwibuka, ntiyibuka, ntitwibuka, ntimwibuka, ntibibuka ; ntiyambara, ntiyemera, ntiyubaka.
- kwumva : ndumva, urumva, sinumva.

### R29. Nombres (leçons 37-38, par. 75-80)
1 à 6 s'accordent (préfixe du verbe, sauf cl.1 sing. umwe) ; 7 à 10 invariables : ndwi, munani, cenda, cumi. Ils suivent le nom. Seuls, 7-10 gardent la voyelle : N'umunani.
Accords de -mwe/-biri : umwe/babiri, umwe/ibiri, imwe/zibiri, kimwe/bibiri, rimwe/abiri, rumwe/zibiri, kamwe/tubiri, bumwe/abiri, kumwe/abiri, hamwe/habiri.
11-19 : icumi na + nombre accordé : abahungu cumi na bane. Dizaines invariables : mirongwibiri... ijana, amajana abiri. 34 moutons = intama mirongwitatu na zine.

### R30. -ngahe « combien » (leçon 39, par. 81)
Préfixes comme les nombres, seulement au pluriel : bangahe, ingahe, zingahe, bingahe, angahe, tungahe, hangahe. Suit le nom. Jamais suivi du présent en -ra- : Umutunzi afise inka zingahe?

### R31. Choix de mots (par. 59, 61, 82, 83)
kugaruka (revenir ici) / gusubira (retourner là-bas) ; kubanza (commencer par) / gutangura (commencer à) ; gutuma (envoyer une personne avec message) / kurungika (envoyer une chose) ; ariko = yamara (mais) / mugabo (cependant ; à ne pas confondre avec umugabo).

Ce que nos générateurs ne font PAS encore et que cette partie enseigne :
1. Impératif : racine seule (Kora!), négatif ntu- + racine en -e (Ntugende!). kuza -> Ngwino.
2. Présent continu : ndiko ndakora, arikw arakora ; négatif sindiko ndakora.
3. Verbe -ri (ndi, uri, ari...) et son négatif (sindi, nturi, ntari, ntituri...) + règle ni/si contre -ri (lieu).
4. Classes 15 (uku-) et 16 (aha-) : ku-/ku-/kwa- et ha-/ha-/ha- ; hari, hariho, Harashushe.
5. Accord d'un sujet double (bi-/vy- ou ba-).
6. Nombres 1-6 accordés, 7-10 invariables, 11-999 (icumi na..., mirongwi..., ijana).
7. -ngahe accordé.
8. Diminutif (aka-/utu-) et augmentatif (iki-) d'un nom.
9. Locatifs : mu/ku + nom sans voyelle initiale, sauf mw/kw devant la classe 5 sing. ; i + nom de lieu.
10. Futur des verbes en u- (azokwubaka).
11. Verbe -fise (mfise, simfise) défectif ; kugira pour le futur.

## c) Pièges de traduction français <-> kirundi

1. Pas d'article : « un homme », « l'homme », « des hommes » = umugabo / abagabo. « Some » ne se traduit pas.
2. ni / si ne vont pas avec un lieu : « L'enfant est à la maison » = Umwana ar'i muhira (pas « ni i muhira »). Mais « Gitega est loin » = Gitega ni kure.
3. n' peut être ni (« est ») ou na (« et ») : Umwana n'umukobwa = « l'enfant est une fille » OU « l'enfant et la fille ». Regarder s'il y a un verbe.
4. -ra- ou pas : « Je travaille » seul = ndakora ; « je veux de l'eau » = ngomba amazi (pas ndagomba). Habitude : -ra- même avec complément.
5. Futur : « J'irai aujourd'hui » = ndagenda uyu musi (présent !). « J'irai demain » = nzogenda ejo. Donc ndagenda peut se traduire par un futur selon le contexte.
6. ejo = hier OU demain : le temps du verbe décide.
7. « son / sa / ses » = -iwe (wiwe, yiwe, ziwe...) ; « ton » = -we. Faux ami facile : wawe = ton, wiwe = son.
8. « chez lui » = i we, « chez nous » = i wacu ; i wacu peut aussi vouloir dire « à la maison ».
9. « Il y a » = hari / hariho ; la réponse s'accorde avec la chose : Ego, biriho (pour ibijumbu).
10. « visage » = mu maso hiwe (pas de mot simple).
11. « dans un bel endroit » = ahantu heza (pas de mu).
12. Sujet double « le pain et la viande sont » -> biri (pas ziri ni iri).
13. Diminutif de politesse : Ngomba agahuzu = « je voudrais un vêtement » (pas forcément petit).
14. Nombre précis avec ubwato/uburiri : singulier (ubwato bubiri = deux bateaux).
15. « commencer » : kubanza (commencer par) contre gutangura (commencer à) ; « envoyer » : gutuma (personne + message) contre kurungika (chose) ; « revenir » : kugaruka (ici) contre gusubira (là-bas).
16. mugabo (cependant) contre umugabo (homme) : seul le ton et la voyelle initiale les distinguent.
17. kwumva = entendre, mais aussi comprendre : Sinumva ikirundi = « Je ne comprends pas le kirundi ».
18. Salutations : Bwakeye (premier bonjour du jour), Mwiriwe (après), N'amahoro? ne se traduit pas mot à mot (« ça va ? »).
19. Les mots religieux du livre (ubutumwa bwiza = évangile, umukiza = sauveur, ubuntu = grâce) sont fréquents ; ubuntu ici = grâce, pas « humanité ».

## Remarques sur le texte source
- Fautes probables du livre (non corrigées dans le JSONL) : « nzu nsha » (L8, sans doute inzu nsha), « inkintu » (L13, vocabulaire, pour ikintu), « umvunja » (L13 ex., pour imvunja), « amyenda » (L5 ex.), « avyaha » (L14 ex.), « mirongibiri » (L38 ex.), « kwubuka » (L40, pour kwibuka), « kubo » (L31 ex., pour kuko ?).
- Les exercices « Translate into English » n'ont pas de traduction : je ne les ai pas mis dans le JSONL (consigne). Ils contiennent pourtant beaucoup de bonnes phrases kirundi qui pourraient être traduites plus tard par un humain.
