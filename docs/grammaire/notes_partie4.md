# Notes partie 4 : Livre II (grammaire avancée) d'E. Cox

Fichier lu en entier (3340 lignes, ch. 1 à 81 + index).
Les références "ch." renvoient aux sections du Livre II.

Rappel des notations utilisées ci-dessous :
- S = préfixe sujet (n-, u-, a-, tu-, mu-, ba- ; et classes : ki-, bi-, ri-, i-, zi-...).
- S+a = préfixe du passé (na-, wa-, ya-, twa-, mwa-, ba-).
- RAC-a = racine avec finale -a (kora). PERF = forme perfective (koze). SUBJ = racine avec -e (kore).
- NEG = si- (1sg) / nti- (les autres) devant le verbe principal.
- NEG dépendant = -ta- après le sujet (nta-, uta-, ata-, tuta-, muta-, bata-), devient -da- devant p t k c f s h (loi de Dahl) : adafise, kudakora, adakekeranya.

## A) Règles de grammaire (avec formation programmable)

### 1. Temps composés du passé (ch. 1)
Forme : AUX = passé de -ri (nari, wari, yari, twari, mwari, bari ; à l'oral yar', war' devant voyelle) + verbe principal.
Le verbe principal donne l'écart de temps :
| écart | verbe principal | exemple |
|---|---|---|
| juste avant | passé sans préfixe : S + PERF | yar' agiye "il venait de partir" |
| plus tôt (même jour ou avant) | passé ordinaire : S+a + PERF | yari yagiye "il était parti" |
| longtemps avant | passé -ara- : S+a + ra + PERF | yari yaragiye "il était parti depuis longtemps" |
- Exemples : "Nshitseyo, yar' agiye" = Quand je suis arrivé, il venait de partir. "Micheli yari yaragiye i Bugande" = Michel était parti en Ouganda (depuis longtemps).
- Négatif : la négation va sur l'auxiliaire : sinari, ntiwari, ntiyari... (ex. "sinari nkirima", ch. 24 ; "sinar' i muhira", ch. 10).
- **Règle importante (ch. 1 par. 2) : un ÉTAT au passé se dit avec la 1re forme** : "Nari ndwaye" = J'étais malade (le livre dit : PAS "narwaye"). "Twari tunezerewe" = nous étions contents. "yar' aryamye" = elle était couchée (Marc 1:30).
- **Passé des verbes défectifs (ch. 1 par. 3)** : nari mfise (j'avais), yar' afise, twari tuzi (nous savions), nari ndi (j'étais), bari bakwiye (ils devaient).

### 2. Temps composés du futur et conditionnel composé (ch. 2)
Forme : AUX = futur de -ba (nzoba, uzoba, azoba, tuzoba, muzoba, bazoba ; cl. 10 zizoba, cl. 7 kizoba) + verbe principal :
- S + RAC-a (présent sans -ra-) : "Nzoba nkora" = je serai en train de travailler.
- ndiko + -ra- présent : "Nzoba ndiko ndakora" = même sens.
- S + PERF : "Nzoba ngiye" = je serai parti (peu avant).
- S+a + PERF : "Nzoba nagiye". S+a+ra + PERF : "Nzoba naragiye" (depuis longtemps).
- Futur d'un état : "zizoba zikanye" = (les habits) seront humides ; "kizoba gihiye" = il sera mûr.
- **Futur des défectifs -ri, -fise, -zi, -kwiye** : nzoba ndi (je serai), nzoba mfise (j'aurai), nzoba nkwiye (je devrai). Le livre dit que "nzoba mfise" est bien plus courant que le futur de -gira.
- Négatif : sinzoba, ntuzoba... : "Sinzoba ndiko ndakora" (ch. 10).
- Conditionnel composé : AUX = conditionnel de -ba (noba, woba, yoba, twoba, mwoba, boba) + même choix : "Noba ngiye" = je serais parti ; "Yoba akwiye kuvuga" = il aurait dû parler.

### 3. Le conditionnel en -o- (Livre I par. 228 ; ch. 3, 10)
Forme présent : S + o + RAC-a. Le sujet + o se combine : n+o = no, u+o = wo, a+o = yo, tu+o = two, mu+o = mwo, ba+o = bo.
- nokujana (je t'emmènerais), woshobora (tu pourrais), Bontuma (s'ils m'envoyaient), yoshobora.
- Négatif : sino- / ntiwo- / ntiyo- / ntitwo- / ntimwo- / ntibo- : "sinosoma" (je ne lirais pas), "ntimwoshobora" (vous ne pourriez pas), "sinoba".
- Passé du conditionnel : S + o + PERF : nogiye (je serais allé), noshimye, nokunze, yociriye (Rom. 3:6), ntiwovuze. Sens : ce qui aurait pu arriver mais n'est pas arrivé.
- Questions : "Nobishobora?" = Pourrais-je le faire ?
- Avec un futur proche : "nohava ngenda", "noca ngenda", "nohava nkazogenda".
- Remarque : le -o- est collé au sujet, PAS au -zo- : nzokora (futur) n'est pas nokora (conditionnel).

### 4. "Si" : les phrases conditionnelles (ch. 3)
- **ni + S+a + RAC-a** (préfixe passé, finale présente, PAS le perfectif) = si / quand (futur) : "Ni nagenda i Bujumbura nzogura ibitabo". "Ni waheza", "Ni twatura", "ni yabazako". Aussi "quand" (ch. 46 par. 3) : "Ni wamubona umubwire".
- Négatif : la forme -ta- est obligatoire, ni est facultatif : "Utabikora uzohanwa" / "N'utabikora uzohanwa". Avec PERF : "Utanditse neza" = si tu n'as pas bien écrit.
- Conditionnel -o- sans ni : "Wokunda noshobora kugufasha".
- asangwa / bisanzwe + verbe = si (réel, présent/passé) : "Asangwa mwabikoze, muzohembwa".
- namba = si (avec doute) : "Namba muzi ico yakoze, mumbarire".
- iyo = si irréel, presque toujours avec -ba :
  - "Iyo mba mfise imodoka nokujana" (iyo + mba + S+PERF ou S+défectif).
  - Forme de -ba après iyo : mba, uba, aba, tuba, muba, baba ; classes : biba, haba. Négatif : iyo ntagenda (forme -ta-).
  - Proposition principale : -o- (noba mbonye / nobikora), ou mba + PERF (mba nje), ou **passé de -ri + infinitif** : "nari kuza" = je serais venu ; "ntiyari gupfa" = il ne serait pas mort ; "sinari kuza".
- **nari + infinitif seul = "j'ai failli"** : "Twari kuzimira" = nous avons failli nous perdre ; "Twari gutsitara" = nous avons failli trébucher.
- iyaba = si irréel : "Iyaba nanyoye umuti mba nkize".
- sans conjonction : verbe au présent ou passé sans préfixe : "Mubikoze neza nzobashima" = si vous le faites bien, je vous féliciterai. "Ukunze, woshobora kumpumanura" (Marc 1:40).
- naho = même si : "Naho mwokora cane ntimwoshobora guheza".

### 5. -ba auxiliaire (ch. 4)
Séries : mba nkora / mba nkoze / mba nakoze / mba narakoze. Sens "je serais / j'aurais". Négatif : simba nje (je ne serais pas venu).
Subjonctif : mbe ndakora ("Reka mbe ndakora gatoya").
Impératif spécial invariable "Ba" + verbe : "Ba muricaye hano" = restez assis ici (Marc 14:32) (ch. 35 par. 3).

### 6. Présent et passé continus (ch. 5)
- S + ri + ko + S + ra + RAC-a : ndiko ndakora, uriko urakora, ariko arakora (à l'oral arikw ararima), turiko turakora, muriko murakora, bariko bararima.
- Autre forme : S + ri + infinitif : "Ndi gukora", "Ari guteka".
- Négatif : ntarikw ararima (il n'est pas en train de cultiver).
- Imparfait : nariko ndakora, bariko bararirimba ; négatif ntitwariko turubaka.
- Sert aussi de participe : "Ndiko ndaza ndamubonye" = en venant, je l'ai vu.

### 7. Passé d'habitude (ch. 6)
- S+a + RAC-a (préfixe passé + finale présente) : nakora, twasohoka, yamukunda.
- "Nkir' umwana nakora mu mirima imisi yose" = Quand j'étais enfant, je travaillais toujours aux champs.
- Sert aussi d'imparfait : "twakora (ou twariko turakora) mu murima".
- **Attention : même forme que après ni (si)**. "nakora" seul = je travaillais (habitude) ; "ni nakora" = si je travaille.

### 8. "Jamais encore" (ch. 7, 8)
- NEG + S+a + ribwa + SUBJ : sinaribwagende, ntiwaribwagende, ntiyaribwagende, ntitwaribwagende, ntimwaribwagende, ntibaribwagende. Avec -bona : ntitwaribwabone (Marc 2:12).
- Dépendant : S+ta + ribwa + SUBJ : ntaribwaze (avant que je sois venu), bitaribwabe (avant que cela n'arrive, cl. 8).
- Affirmatif après "nta ho" : "Nta ho uribwabone ben' ivyo?" (u + ribwa + bone, sans -a-).
- Autre façon : -igera (passé -igeze) + infinitif : "Sinigeze kugenda i Bururi".
- "Jamais" au futur : nta ho + futur de kwigera ("Nta ho azokwigera abikora"), nta ho + futur ("Nta ho nzokora ivyo"), sinzokwigera + verbe ("Sinzokwigera mbesha"), ou négatif futur de kuruha ("Ntazoruha abikora").

### 9. Verbes auxiliaires "tout de suite" (ch. 9)
- -ca + verbe : "Nca nkuzanira ivyo bitabo" ; "Aca arabahamagara" ; passé "Yaciye agenda" ; futur "bazoca bisonzesha". Le 2e verbe suit la règle -ra- (avec -ra- s'il n'y a rien après dans la proposition : "Aca arabahamagara").
- -hava (un peu moins immédiat) : futur azohava agenda ; passé yahavuye agenda.
- -gira + subjonctif = "être sur le point de" : "Umuganga agira agende i muhira" ; "Ngira ntume integuza yanje" (Marc 1:2).

### 10. Subjonctif et impératif (ch. 11 à 13)
- Subjonctif présent : S + RAC avec -a -> -e : agende, tuze, mbahamagare (n+b = mb), mvyandike (n+vy = mvy). Négatif : NEG + S + SUBJ : singende, ntibisonzeshe, ntase.
- 1sg avec pronom objet : -ra- possible : "Ndabahamagare?" = "Mbahamagare?" = Est-ce que je les appelle ? Sans objet : jamais -ra-.
- Subjonctif futur (après aujourd'hui) : -za auxiliaire au subjonctif + verbe au subjonctif : "tuze turonke", "tuze tuje", "az' abore" (élision devant voyelle).
- Autre subjonctif futur : S + zo + SUBJ : "ngw azoze ejo" (qu'il vienne demain), "tuzobafashe".
- Impératif futur : = subjonctif futur : "Uz' ubikore ejo" / "Uzobikore ejo".
- Impératif futur fort : S + razo + RAC-a : "Urazoza ejo" (viens demain sans faute), "Murazogenda".
- Impératif 2e pl. court : racine avec -e : "Gende!" = "Mugende!", "Rime!".
- Subjonctif après une affirmation pour un contraste négatif (ch. 12) : "abigishwa bawe ntibisonzeshe".
- Subjonctif pour une suite d'actions futures (ch. 13) : 1er verbe au futur, les autres au subjonctif : "Nzokubita umwungere, intama zisanzare".

### 11. Futur en -ro- (ch. 14)
Comme -zo- mais avec -ro- (régional) : ndokora (n + ro -> ndo), arogenda.

### 12. Temps en -ribu- (ch. 15)
- S + ribu + SUBJ = futur proche d'aujourd'hui : ndibukore, uribukore, aribukore, turibukore, muribukore, baribukore.
- n + ri -> ndi (règle n+r = nd). Devant voyelle : ribu -> ribw : "ndibwirukire" (kwiruka).
- Négatif : sindibu- / ntu-ribu... ; dépendant : utaribuhe ("Ico utaribuhe umwana").
- Sens "pouvoir/devoir" : "Nta ko ndibugire" = je n'y peux rien.
- Composés avec -ba : aribube akora / aribube akoze / aribube arakora / aribube yakoze : "Ndibube mpita", "Sindibube ndima", "Uribube uraza".

### 13. Passé sans préfixe (ch. 16, 22)
- S + PERF : uvuze, tubonye, agiye.
- En proposition dépendante, -ra- tombe : "aragiye" (il vient de partir) -> "kukw agiye" (parce qu'il vient de partir).
- C'est le "participe" : "Mbibonye, naciye mpamagara umuganga" = L'ayant vu, j'ai aussitôt appelé le médecin.
- Avec kubona / kwumva, le 2e verbe est au présent sans préfixe : "Namubonye agendagenda" = je l'ai vu marcher.

### 14. Infixe -kazo- (ch. 17, 10)
Quand on voudrait -ka- (suite) mais à un autre temps (futur) : "kand' akazokwishurwa" (Rom. 11:35) ; "nohava nkazogenda". Sert aussi de négatif futur fort (pas d'exemple écrit).

### 15. Optatif (ch. 18)
- icompa (1sg) / icoduha (1pl) + verbe avec -ka- après le sujet : "Icompa akaza" = si seulement il venait ; "Icoduha tugashikayo" (ka -> ga devant sh, loi de Dahl).
  Négatif : icompa + subjonctif négatif : "Icompa singende", "Icompa ntazoze".
- S + ka + ba + PERF : "Akaba akize", "Nkaba ngarutse".
- -raka- : S + raka + RAC-a : ndakagenda, urakagenda, arakagenda. Souhaits : "Uragahezagirwa n'Imana!", "Uragakomera!", "Urakaza" (bienvenue), "Biragahera!" (à Dieu ne plaise). Négatif : NEG + S + ka + SUBJ : sinkagende, sinkarime, ntukagende.
- iyo + présent sans préfixe ou composé avec -ba : "Iyo bwira!" = si seulement c'était le soir !

### 16. Impératifs négatifs forts (ch. 19, 20)
- -oye + infinitif : noye, woye, yoye, twoye, mwoye, boye : "Mwoye gutinya" = n'ayez pas peur ; "ngo yoye kugwa" = pour qu'il ne tombe pas.
- NEG + S + ka + SUBJ (ka -> ga devant p t k c f s h) : "Ntimukabeshe", "Ntugasubire kuvuga", "Ntihakagire...".
- -ka- emphatique dans un négatif non impératif : "ntarakazuka" (1 Cor. 15:16).
- "Ne dis à personne" : négatif de -gira : "Ntugire uwo ubibwira", "Ntihagire ubimenya". Récit : "Ntihagira usubira..." = personne n'osa plus.

### 17. Infixe intensif -na- (ch. 21)
Après le signe de temps, avant le pronom objet : nda + na + ki + rondera = "Ndanakirondera" ; "Sindanamuzi" = je ne le connais pas du tout.

### 18. Infinitifs futur et négatif (ch. 23)
- Futur : ku + zo + racine : kuzobona, kuzogenda, kuzokwibuka (zo + kw devant voyelle).
- Négatif : ku + ta + racine : kutagenda, kudakora (Dahl : ta -> da devant k), kutizera (ta + i -> ti).
- Futur négatif : kutazogenda.
- "Sinabigishije kuvuga gurtyo" (je ne vous ai pas appris à...) ≠ "Nabigishije kutavuga gurtyo" (je vous ai appris à ne pas...).

### 19. "Encore" / "ne... plus" au passé et futur (ch. 24)
AUX -ri (ou -ba) + S + ki + verbe : "bari bakirwaye" = ils étaient encore malades ; "sinari nkirima" = je ne cultivais plus (négation sur l'auxiliaire, -ki- sur le verbe) ; "yar' akiri muri twebwe".

### 20. Autres auxiliaires
- -mara (passé sans préfixe) + infinitif = "après avoir" : "Umaze gukora ivyo, tangura...", "Amaze gutaha, yabonye abashitsi" (ch. 36).
- -ruha + verbe = arriver à grand-peine : "Nturaruha ubitahura?" (ch. 37).
- -sanga (sanzwe) = état déjà existant : "Yar' asanzwe arwaye atarakomereka" (ch. 38).
- kwama / guhora + présent sans préfixe = toujours : "Mpora ntangura akazi isaha zibiri", "Simpora nkora ivyo", "Ntituzokwama tubahanura" (ch. 34). Le temps et la négation vont sur kwama/guhora.
- -heza = "puis" : "araheza arabasezera" (ch. 44). -bona + infinitif = pouvoir, ou "alors" (ch. 45).
- Intensif par l'infinitif : "Kurima narimye" = j'ai cultivé dur (ch. 32).

### 21. Pronoms objets
- Après n- ou sin-, avec les objets -wu-, -yi-, -ya-, on met -ra- même si le temps ne le veut pas : "ndawugomba" (pas nwugomba), "sindayifise" (pas sinyifise) (ch. 41).
- Objet placé avant le verbe = toujours repris par un pronom dans le verbe : "Amavuta ayamusuka ku mutwe" (Marc 14:3) (ch. 42).

### 22. Dérivations verbales (ch. 26 à 31)
Suffixes (on ne peut pas les ajouter à volonté) :
- -agura : vite, souvent, à fond : kumena -> kumenagura.
- -agira : intensif : gukanda -> gukandagira.
- -anga : intensif : gukoma -> gukomanga.
- -kara : rend intransitif : guta -> gutakara.
- -ama : état résultant : guheta -> guhetama.
- -iriza / -ereza : répété : gusaba -> gusabiriza ; kwumva -> kwumviriza.
- -ana : réciproque, intensif, à tour de rôle : kwima -> kwimana.
- -ura : rend transitif ou contraire : kugaruka -> kugarura ; kwugara -> kwugurura ; guhisha -> guhishura.
- -uka / -oka / -ika / -eka : rend intransitif ou "faisable" : kumena -> kumeneka ; kubona -> kuboneka ; gushobora -> gushoboka ; gusoma -> gusomeka.
- Contraire d'un intransitif : -uka : gutinya -> gutinyuka ; kuruha -> kuruhuka.
- Prépositionnel -ira/-era avec sens spécial : kwumva -> kwumvira (obéir), gukunda -> gukundira (permettre). + ubusa = "pour rien" : "Yabikoreye ubusa". Réciproque + prépositionnel : -iranira : kwandikiranira.
- Causatifs irréguliers : -ka -> -tsa (kwibuka -> kwibutsa), -ma -> -mya (kuzima -> kuzimya), -ba -> -vya (guteba -> gutevya, gusiba -> gusivya), -na -> -nya (guterana -> guteranya), -ha -> -sha (gukariha -> gukarisha).
- Réfléchi intensif (souvent + prépositionnel) : kwisinzirira, kwigendera, kwihakana (ch. 33).
- Le kirundi préfère l'intransitif : "Igitabo catakaye" plutôt que "Nataye igitabo" (ch. 27).

### 23. Noms tirés des verbes (ch. 51)
- finale -a -> -e (celui qui) : gutwara -> umutware, gukena -> umukene.
- -a -> -i (agent) : guhiga -> umuhigi, kubesha -> umubeshi.
- -a -> -o (résultat) : kugenda -> urugendo, kuririmba -> indirimbo.
- dernière syllabe changée (agent, comme le perfectif) : gukora -> umukozi, kwiba -> umwivyi, kuroba -> umurovyi.

### 24. Autres points
- "quand" : aho, hamwe (passé), igihe, iyo, ni + S+a + RAC-a, ou passé sans préfixe (ch. 46).
- "après X jours" : Hashize + durée (ch. 47).
- "sans" : verbe à la forme -ta- : "Yaje mw ishuli adafise igitabo" (ch. 73).
- ko = que / puisque / si (whether) / pourquoi (ch. 71). Après ko, a + voyelle : "kw azoza".
- Comparaison "plus petit que" : "ni muto inyuma y'uwawe" ; "moins que" = négatif : "Minani ntazi ubwenge nka Gahungu" (ch. 54).
- "trop" n'existe pas : cane (ch. 79).
- ni + pronom = "c'est lui qui" : "Ni je nabikoze" ; en dépendant : ari yo (ch. 57).
- Possessif en pronom : voyelle initiale + possessif : ivyanje, urwiwe ; rwanje invariable (ch. 58). ivya + nom = "au sujet de" ; ivyo + infinitif (ch. 58 par. 5).
- voici/voilà : ng + démonstratif : nguyu, ngaba, ngizi, ngivyo, ngabariya (ch. 62).
- nya + pronom = excellent : ikirundi nyaco, umwana nyawe (ch. 63).
- Vocatif : le nom perd sa voyelle initiale : "Mwananje", "Bagabo", "Yemwe bana!" (ch. 70).
- Nombres : "ubwa kabiri" = la 2e fois ; "umusi ugira kane" = le 4e jour (car "umusi wa kane" = jeudi) (ch. 67). Dizaines sans mirongw : "Ine n'atanu" = 45 (ch. 68). Fractions : "igice kimwe ca gatatu" = 1/3 (ch. 69).
- Heures : la 1re heure = 7h ; "isaha zibiri" = 8h ; "isaha sita" = midi (ch. 34, 81).

## B) Comparaison avec nos générateurs

### CONFIRMÉ
- Futur -zo- + voyelle -> zo + kw : "kuzokwibuka" (ch. 23), "azokwakwa" (Marc 4:25), "Sinzokwigera" (ch. 8).
- Négatif futur 1sg sinzo- : "Sinzokwigera mbesha", "Sinzoba ndiko ndakora".
- Négatif présent / passé : "Simpora nkora" (si + n + p -> simp-), "sinari", "ntimwoshobora", "ntibisonzeshe".
- Sons n+h -> mp : "mpora" (guhora), "mpava" (-hava), "mpita" (guhita), "mpiriwe" ; n+b -> mb : "mbahamagare", "mbe" ; n+r -> nd : "ndibukore", "ndokora".
- Loi de Dahl pour ka -> ga : "Ntugasubire", "tugashikayo" ; et ta -> da : "adafise", "kudakora".
- Passé sans préfixe = forme "parfait" (nkoze, agiye) : confirmé, et le livre dit à quoi il sert (participe, proposition dépendante, "venir de").
- -ra- tombe en proposition dépendante : "aragiye" -> "kukw agiye" (ch. 16).
- Après un démonstratif, le nom perd sa voyelle initiale : "uwo munyu", "iyo nzira", "wa wundi mwana".

### FAUX ou INCOMPLET
1. **INCOMPLET (risque d'erreur grave) : passé des verbes d'état.** Notre générateur fait "narwaye" pour "j'étais malade". Le livre dit : "Nari ndwaye – I was sick (not, narwaye)" (ch. 1 par. 2). Pour -rwara, -ryama, -nezerwa, -fise, -zi, -kwiye, -ri, le passé "j'étais / j'avais" = nari + S + PERF : nari ndwaye, nari mfise, twari tuzi, nari ndi. ("narwaye" veut plutôt dire "je suis tombé malade".)
2. **INCOMPLET : futur des défectifs.** On ne peut pas faire "nzofise" ou "nzozi". Il faut nzoba mfise, nzoba ndi, nzoba nkwiye (ch. 2 par. 3).
3. **INCOMPLET : pronoms objets -wu-, -yi-, -ya- après n-/sin-** : il faut -ra- : "ndawugomba", "sindayifise" (ch. 41). À coder quand on ajoutera les pronoms objets.
4. **INCOMPLET : la forme S+a + RAC-a (nakora, twakora)**. Notre générateur ne connaît que S+a + PERF (nakoze). Or nakora existe et a 3 sens : passé d'habitude ("j'avais l'habitude de travailler", ch. 6), imparfait ("je travaillais"), et après ni = "si/quand" futur ("ni nagenda" = si je vais, ch. 3). Il ne faut PAS la confondre avec le passé.
5. **Démonstratif cl. 1 "ce...là"** : notre table dit "uwo" ; le livre utilise aussi "uyo" ("Uyo n'umwana nyawe", ch. 63). Les deux existent ; ce n'est pas une erreur mais une variante.
6. **Numérotation des classes** : Cox utilise sa PROPRE numérotation, pas celle des grammaires bantoues. Ch. 48 : "isandugu, isaha, isuka" = "3e classe singulier, 5e pluriel" chez Cox = chez nous cl. 9 (accord i-) au singulier et cl. 6 (ama-) au pluriel : "ikaramu imwe, amakaramu menshi". Ne jamais copier "3e classe" de Cox dans notre table sans conversion.
7. Questions ouvertes ("uwu/uyu" cl. 3, "iro/iryo", "narize", "ndya/mva/mpfa") : le Livre II n'y répond pas directement. Seul indice : "Ndokora" et "ndibukore" confirment n + r -> nd.

## C) Pièges de traduction français <-> kirundi

1. **"J'étais malade" ≠ "narwaye".** Utiliser "nari ndwaye". De même "j'avais" = "nari mfise", "je savais" = "nari nzi" (ch. 1).
2. **Le "si" dépend du sens** : si réel futur = ni + nakora (pas nakoze) ; si irréel = iyo/iyaba + mba ... ; si avec doute = namba ; sans conjonction = passé sans préfixe ("Mubikoze neza nzobashima").
3. **Négatif après "si", "quand", "sans", relatif** : on n'utilise PAS nti-/si-, mais -ta- : "utabikora", "atavuze", "adafise".
4. **"nari kuza"** veut dire "je serais venu" (après un si irréel) ou "j'ai failli venir", PAS "j'allais venir".
5. **"Il a nié qu'il le connaissait"** = "Yahakanje kw atamuzi" : en kirundi le verbe après -hakana est NÉGATIF (ch. 33).
6. **Pronoms objets** : un nom déjà cité ou placé avant le verbe est repris dans le verbe : "Amavuta ayamusuka" (cl. 6), "Ufise amapfundo abiri, rimwe n'arihe" (cl. 5), "Ndanakirondera" (cl. 7). En français : "le / la / les".
7. **"Ne le dis à personne"** ne se traduit pas mot à mot : "Ntugire uwo ubibwira" (mot à mot : n'aie pas celui à qui tu le dis).
8. **"Plus ... que"** : souvent sans comparatif : "Iciza n'ikihe ?" = qu'est-ce qui vaut mieux ? ; "moins que" = phrase négative.
9. **"Trop"** = cane (très). "Iyi mpuzu ni ntoya cane" = trop petite.
10. **Intransitif préféré** : "Igitabo catakaye" = j'ai perdu le livre (mot à mot : le livre s'est perdu). En français, on dit plutôt "j'ai perdu".
11. **Faux amis de -gura** : kugura = acheter ; dans "Iyo nkoko urayigura angahe?" l'anglais dit "selling", mais le kirundi dit "acheter". Vérifier le sens du kirundi, pas celui de l'anglais.
12. **"Le 4e jour"** ≠ "umusi wa kane" (= jeudi) ; dire "umusi ugira kane".
13. **Heures** : "isaha zibiri" = 8h, "isaha sita" = midi (on compte depuis 7h).
14. **Urakaza** (neza) = bienvenue (optatif), pas "tu viens".
15. **Classes de Cox ≠ classes bantoues** (voir B6).
16. **Coquilles du livre** (gardées telles quelles, marquées "à vérifier") : "nogufahsa", "yobayaje", "mba ndiko warakize", "Ntiwariko turubaka", "Uburyo ... nyabwo", "guhmanura", "Bukirsazi". Ne pas apprendre ces formes comme modèles.
